# Initial correctness and IR-growth checks

These checks cover production source
[`8ba1bc79`](https://github.com/den-run-ai/pystachy/commit/8ba1bc7928cdef48db1c59a8219c029d018b7b2a).
The later `f969e355` change adds a cheap caller-side size guard; its hosted replay
is recorded separately in `candidate-gate-hosted-ir.json`. The initial native
binary does not certify that later source revision. A final source freeze and
fresh native validation are required after the inlining-policy screen.

## Deterministic growth

The baseline is main `f7103067545b43cdcd8ce20dc66b1571425b3a8d`. The inputs are
generated by the following exact template for each shape and size in
`baseline-ir.json`:

```python
items = [str(j - n // 2) if shape == "int" else
         repr((j - n // 2) * .125) if shape == "float" else
         ("True" if j % 3 else "False") if shape == "bool" else
         f"({j}, {j % 31})" for j in range(n)]
source = ("def make_values():\n    return [" + ", ".join(items) +
          "]\nvalues = make_values()\nprint(len(values), values[0], values[-1])\n")
```

The baseline records include source hashes and raw IR byte/line counts. Their
one-off hosted frontend wall times include an initially cold Python bytecode
cache and are **not a controlled performance comparison**. `candidate-ir.json`
records nine exact hosted/native IR matches on the same scalar inputs.
`candidate-gate-hosted-ir.json` records the unchanged nine hashes after the guard.
Tuple items remain outside the fast path.

`tools/test_typed_list_constants.py` separately checks the initializer function
at 32, 256 and 2,048 items. It passes on the candidate and fails on the old source.
The first negative-control test script stopped with an additional `IndexError`
after the expected assertion failures; the corrected script records only the
intended baseline growth failures. Both attempts are preserved.

## Native and runtime checks

`validation.json` records the retained native artifacts and their hashes. The
ordinary `make` performed two identical O2 native builds, three matching compiler
IR witnesses and three matching runtime IR witnesses. `make check-fast`, the
runtime ABI/effect checker (645 entries), normal/collection-on-every-allocation
`listprobe`, and 18 frame-state ownership tests passed. This initial build occurred
while unrelated external compilation was visible on the host; its duration is
not performance evidence.

The focused `tests/run.sh ./pystachy 'jit aot'` selection was:

- `tests/programs/containers/large_scalar_literals.py`
- `tests/programs/containers/large_scalar_literal_order.py`
- `tests/programs/inference/dynany_large_scalar_literal_identity.py`
- `tests/programs/containers/tuple_constant_identity.py`
- `tests/programs/inference/dynany_identity_list_items.py`
- `tests/programs/inference/dynany_identity_list_mutations.py`
- `tests/programs/numbers/python_int_lists.py`
- `tests/programs/numbers/python_int_tuple_lists.py`

With `PYSTACHY_JOBS=2`, the corrected selection passed all 16 JIT/AOT comparisons
and all 16 again with `PYSTACHY_GC_STRESS_PROGRAM=1`. The first run passed 14 and
failed two because the new identity fixture used unsupported direct `is` on typed
floats. Commit `92fcded3` changes the observation to an `Any`-typed helper, without
changing the CPython recording or production code. Three new fixture IR checks
also passed LLVM assembly and Pystachy's IR checker.

The production implementation was independently reviewed. The review found one
missing program-lifetime state classification (`lconsts`), corrected in
`34e4f59e`; it found no semantic/runtime blocker in the bounded scalar path. It
also requested the escaping/local constructor and inlining controls before making
any performance-quality claim.

`ir-library-inputs.json` proves identical hashes for 91 library/runtime.py files
before the later strict IR corpus comparison. Runtime C intentionally differs and
is not read by `ir` or `rt`; this is not permission to share runtime homes for
native linking.

These initial checks are not full local `make verify`, macOS validation, or a
complete final-source IR/diagnostics corpus comparison.
