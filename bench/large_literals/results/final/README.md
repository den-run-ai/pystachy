# Large scalar list initialization: final evaluation

Production is frozen at `6ad66566a826e1acef0da4601d698b121ad5662e`; benchmark/validation head `6f51dd2d` adds only the preceding policy evidence. Main baseline is `f7103067545b43cdcd8ce20dc66b1571425b3a8d`. ## Result and policy

Large homogeneous scalar displays use immutable typed data and one copy into a fresh scanned header plus atomic item array. Fixed-width ints, literal floats and bools qualify at 32 items; typing/coercion still precedes the fast path. Small, mixed, pointer-bearing, tuple, computed, dynamic-Any and promoting-int cases keep their ordinary construction. Exact float bits, freshness, aliases, mutation and GC behavior are covered by the focused tests.

The [policy screen](../policy-screen/README.md) showed that forced `noinline` is unnecessary for the observed optimized-code bound. The final helper uses normal LLVM eligibility. The final C-source builds reproduce the screen’s attribute-only normal-eligibility executable bytes for both repeated workloads. This bridges the screen to the actual source policy; it is not an assertion that every target or LLVM version chooses the same expansion.

## Repeated narrow measurements

Three interleaved frozen-IR backend pairs and five interleaved execution pairs per workload, pinned to CPU 3 on AMD EPYC 9V74 80-Core Processor / x86-64 Linux with LLVM 18.1.3 and CPython 3.13.16. The machine is a shared host; observed ranges and load are preserved, not treated as confidence intervals. All 12 build witnesses and 20 timed execution witnesses matched CPython stdout, empty stderr and exit status. Every rebuild within a policy/workload produced identical executable bytes. Current checkout source supplied the hosted frontend; no stale native binary was used.

The backend is a separated Clang O2/codegen replay. It excludes runtime preparation, frontend emission, disassembly and size inspection. Execution includes fresh-process startup and one full-list print; repetitions initialize at least 100 million elements (3,125,000 local-32 constructions and 24,415 escaping-4096 constructions). These are scalar-list workload measurements, not compiler-bootstrap or mypyc comparison results.
