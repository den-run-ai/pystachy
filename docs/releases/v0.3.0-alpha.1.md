This alpha focuses on compiler foundations, selected allocation reductions and
reusable applications. It includes the v0.2.1 correctness changes.

- Index exception bindings once per function instead of repeatedly walking the
  same syntax tree.
- Preserve list lengths and concrete read effects in typed IR. Prove selected
  invariant forward-loop bounds while retaining checked fallbacks when mutation,
  aliasing or an unknown call prevents a proof.
- Initialize large homogeneous scalar list literals from constant data, construct
  selected runtime tuples directly and keep private optional scalar locals
  unboxed when their uses permit it. Escaping values retain their existing
  representation and identity contracts.
- Reduce temporary LLVM text storage without changing emitted LLVM IR.
- Enable persistent native program caching for eligible Linux ORC executions.
  Cache validation includes source and import resolution, compiler/runtime inputs,
  toolchain identity and supported settings. Ineligible runs use the existing
  execution path; `PYSTACHY_PROGRAM_CACHE=0` disables the cache.
- Add an educational byte-BPE train/encode/decode showcase and a bounded
  integer-ID bitmap filtering example, with independent correctness oracles and
  scoped performance evidence.

Bitmap filtering can lose to sets on sparse inputs. Benchmark evidence remains tied
to its recorded revisions and settings.

The compiler is experimental. This alpha retains the existing collector and
concurrency model. Broader class/reducer support, ctypes, retained buffers,
callback specialization, runtime migration and optional GUI work remain separate
release candidates.
