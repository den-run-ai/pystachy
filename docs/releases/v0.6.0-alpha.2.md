Pystachy v0.6.0-alpha.2 continues the v0.6.0 series. It compiles more of the class and
typing patterns in mypy's own code, uses classes as values, holds objects beside numbers and
strings in unions and in runtime-length tuples, asks objects for `__index__` where CPython
does, and extends `decimal`. Pystachy remains an experimental compiler for a typed subset of
Python.

## Classes and generics

- A class may name several method-only secondary bases: mypyc traits, generic bases, and
  bases that declare attributes by annotation, define `@property` getters or extend each
  other. An override may return a class derived from the one the base's method returns.
  ([#1335](https://github.com/den-run-ai/pystachy/pull/1335),
  [#1350](https://github.com/den-run-ai/pystachy/pull/1350),
  [#1373](https://github.com/den-run-ai/pystachy/pull/1373),
  [#1457](https://github.com/den-run-ai/pystachy/pull/1457),
  [#1463](https://github.com/den-run-ai/pystachy/pull/1463))
- A class is generic in the type variables its bases pass on and may derive from
  `Iterator[...]` or `Iterable[...]`. `TypeVar` takes bounds and constraints that are types,
  and objects of two sibling classes take their nearest common base.
  ([#1352](https://github.com/den-run-ai/pystachy/pull/1352),
  [#1391](https://github.com/den-run-ai/pystachy/pull/1391),
  [#1346](https://github.com/den-run-ai/pystachy/pull/1346),
  [#1243](https://github.com/den-run-ai/pystachy/pull/1243))
- `typing.final`, `mypy_extensions.trait` and `mypyc_attr(...)` may decorate classes, and an
  alias of `FlexibleAlias[T, X]` stands for `X`, as in mypy.
  ([#1275](https://github.com/den-run-ai/pystachy/pull/1275),
  [#1342](https://github.com/den-run-ai/pystachy/pull/1342))
- Enum members run the class's `__init__`; a `__new__` in the documented form makes the
  members, and `_simple_enum` and `global_enum` work.
  ([#1321](https://github.com/den-run-ai/pystachy/pull/1321),
  [#1348](https://github.com/den-run-ai/pystachy/pull/1348))

## Classes as values

`type[C]` holds the class object of `C` or of a subclass in variables, fields, defaults and
containers. Class objects answer `isinstance()` and `issubclass()`, construct objects, and
read the class attributes and call the class and static methods of the class they are.
`type[object]`, or `type`, holds any class's class object, including builtin classes such as
`int`, and `type(x)` gives one; calling a `type[object]` value stays rejected.
([#1315](https://github.com/den-run-ai/pystachy/pull/1315),
[#1361](https://github.com/den-run-ai/pystachy/pull/1361),
[#1372](https://github.com/den-run-ai/pystachy/pull/1372),
[#1406](https://github.com/den-run-ai/pystachy/pull/1406),
[#1407](https://github.com/den-run-ai/pystachy/pull/1407))

## Unions, tuples and sets

- A union may hold `int`, `float`, `bool` or `str` beside objects of the program's classes,
  dispatching operators and comparisons on the member it holds, and `sum()` adds objects in
  CPython's order. A union may also hold a `Callable` beside scalars and containers.
  ([#1369](https://github.com/den-run-ai/pystachy/pull/1369),
  [#1448](https://github.com/den-run-ai/pystachy/pull/1448))
- `isinstance()`, `callable()`, `None` and truth tests of `x.a` narrow the reads that follow
  until the attribute may change.
  ([#1453](https://github.com/den-run-ai/pystachy/pull/1453))
- Runtime-length tuples hold objects of a class or of a union of classes, and tuples of
  other lengths join into them.
  ([#1292](https://github.com/den-run-ai/pystachy/pull/1292),
  [#1294](https://github.com/den-run-ai/pystachy/pull/1294),
  [#1297](https://github.com/den-run-ai/pystachy/pull/1297))
- `AbstractSet[T]` holds sets and frozensets. Frozensets hash as in CPython and serve as
  dict keys and set elements.
  ([#1413](https://github.com/den-run-ai/pystachy/pull/1413),
  [#1380](https://github.com/den-run-ai/pystachy/pull/1380))

## Fields, globals and defaults

- Fields take their types from module constants, annotated module globals and their items,
  and globals whose bindings agree on a type.
  ([#1295](https://github.com/den-run-ai/pystachy/pull/1295),
  [#1368](https://github.com/den-run-ai/pystachy/pull/1368),
  [#1375](https://github.com/den-run-ai/pystachy/pull/1375))
- A parameter whose default is an `object()` sentinel keeps its annotated type, and a
  read-only `Sequence[T] = ()` default compiles as an empty list. `if NAME:` directly after
  `NAME = True` or `NAME = False` is decided when compiling.
  ([#1362](https://github.com/den-run-ai/pystachy/pull/1362),
  [#1390](https://github.com/den-run-ai/pystachy/pull/1390),
  [#1338](https://github.com/den-run-ai/pystachy/pull/1338))
- Type alias values and evaluated annotations raise CPython's `AttributeError` when they
  read a module attribute that a circular import has not bound yet.
  ([#1399](https://github.com/den-run-ai/pystachy/pull/1399),
  [#1400](https://github.com/den-run-ai/pystachy/pull/1400))

## The index protocol

Subscripts, slices, `range()` and the integer parameters of `list`, `tuple` and `str`
methods ask objects for `__index__()` and take an `Any` index, in CPython's order. In `%`
formatting, `%x`, `%o` and `%c` ask for `__index__()`, and `%d` asks for `__int__()` first.
([#1367](https://github.com/den-run-ai/pystachy/pull/1367),
[#1396](https://github.com/den-run-ai/pystachy/pull/1396),
[#1425](https://github.com/den-run-ai/pystachy/pull/1425))

## Standard library and repairs

- `decimal` adds `sum()` of `Decimal` values, `exp()`, `ln()`, `log10()` and powers with a
  `Decimal` exponent, correctly rounded as libmpdec computes them, and the remaining
  `next_*`, `compare_*` and `*_mag` operations.
  ([#1370](https://github.com/den-run-ai/pystachy/pull/1370))
- `str` methods map and test the case of non-ASCII text by CPython's per-character rules;
  `bytes` methods stay ASCII-only.
  ([#1518](https://github.com/den-run-ai/pystachy/pull/1518))
- `librt.internal`, mypy's cache codec, matches the C extension byte for byte.
  ([#1276](https://github.com/den-run-ai/pystachy/pull/1276))
- `format()` of a `complex` raises `ValueError` for a width or precision past
  `sys.maxsize`, as CPython does.
  ([#1521](https://github.com/den-run-ai/pystachy/issues/1521))

## Known limits and platforms

Dynamic `Any` and promoting integers remain experimental opt-ins. Mapping patterns, async,
full native mypy and broad concurrency are outside this alpha. The
[compatibility reference](https://github.com/den-run-ai/pystachy/blob/v0.6.0-alpha.2/docs/language/compatibility.md)
lists the documented deviations.

| Native archive | Requirements |
|---|---|
| Linux x86-64 / AArch64 | Ubuntu 24.04 or compatible glibc 2.39+ Linux; LLVM 18 |
| macOS arm64 / x86-64 | macOS 15+, Xcode Command Line Tools; LLVM 20 |

Archives and Docker run without Python; the hosted compiler needs Python 3.11+ and reports
`commit unknown` when installed with pip. Full verification targets Linux x86-64 and ARM64
with CPython 3.13.16. Linux archives are not manylinux packages. Prereleases leave the
stable `latest` unchanged.
