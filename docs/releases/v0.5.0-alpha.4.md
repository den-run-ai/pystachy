Pystachy v0.5.0-alpha.4 adds `hashlib` and `hmac`, explains native pytest
failures and selects tests by node ID, and extends alpha.3's numeric identity and
constructor work to optional generator yields and standalone templates. It remains an
experimental compiler for a typed subset of Python.

## Hashing

The new `hashlib` subset implements MD5, SHA-1, SHA-224 and SHA-256 over `bytes` from
RFC 1321 and FIPS 180-4: the four constructors, `new()`, `update()`, `digest()`,
`hexdigest()`, `copy()`, `name`, `digest_size` and `block_size`. Other algorithms are
compile-time errors, and `algorithms_guaranteed` names these four. An optional
`import hashlib` now succeeds, so its `try` branch cannot fall back from other algorithms.
[#1288](https://github.com/den-run-ai/pystachy/pull/1288),
[library limits](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.4/lib/compatibility.md)

`hmac` implements RFC 2104 over those hashes: `new()`, `digest()`, `HMAC` objects with
`update()`, `digest()`, `hexdigest()` and `copy()`, and `compare_digest()`. A hash is named
by string or given as a `hashlib` constructor; keys and messages are `bytes`.
[#1427](https://github.com/den-run-ai/pystachy/pull/1427)

## Native pytest

Failures show the exception type and message, and comparison assertions add their operand
values, each evaluated once in order. A disagreement with pytest names the case and phase, and
a summary counts outcomes. Node IDs select tests; label marks, `usefixtures`, decorator
`skipif` expressions and `__main__` guards are accepted.
[#1264](https://github.com/den-run-ai/pystachy/pull/1264),
[runner](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.4/docs/pytest-native.md)

## Identity and constructors

Optional `int` and `float` generator yields keep their source objects when they cross into
dynamic `Any`, including through `yield from`, which can widen a scalar channel to its optional
type. Owned delegates close when narrowing an optional integer fails. Optional integer channels
keep their checked 64-bit boundary in promoting-int modules.
[#1495](https://github.com/den-run-ai/pystachy/pull/1495),
[boundary contract](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.4/docs/dynamic-any.md)

A standalone template construction now discovers the fixed-layout constructors it
requires before a subclass is used: `errors = Errors(Options(...))` can precede
`Checker(errors)` when `Options` has independently annotated storage, including through
imported, aliased, qualified and quoted annotations. Programs that alpha.3 rejected for
this now compile; unrelated imported subclasses stay inactive.
[Generic classes](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.4/docs/language/typing.md#class-templates-and-generic-classes)

## Verification, limits and platforms

Lean boundary checks now compare list identity companions with distinct physical storage and
validate emitted Clang layouts. These bounded models do not prove general aliasing or collector
correctness. Dynamic `Any` and promoting integers remain experimental opt-ins; async, full
native mypy and broad concurrency remain outside this release.
[Verification scope](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.4/tools/lean_boundary/README.md)

Native archives target Linux x86-64/AArch64 with glibc 2.39+ and LLVM 18, and macOS
arm64/x86-64 with macOS 15+, Xcode Command Line Tools and LLVM 20. Linux archives
are not manylinux packages. Archives and Docker run without Python; the hosted compiler
needs Python 3.11+. This prerelease keeps stable defaults at v0.4.0.
