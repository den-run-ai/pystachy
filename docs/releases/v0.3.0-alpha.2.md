This alpha broadens bounded language interoperability and runtime dogfooding. It
includes the v0.3.0-alpha.1 compiler foundations.

- Add canonical class values for Dynamic `Any`, exact-type reducer registries and
  bounded reconstruction through stored classes. Fixed-signature dynamic callables
  can consume supported runtime `*args` and `**kwargs` packs.
- Share class-tag error-name tables to reduce repeated inherited-field error paths
  while preserving diagnostics.
- Add a static `ctypes` compatibility layer over the existing native FFI and remove
  selected temporary conversion allocations. Supported declarations include scalar
  arguments, byte strings, nullable pointers, `c_void_p` cells, `POINTER(c_void_p)`,
  `byref` and `string_at`.
- Add optional retained CPU buffers for embedded CPython and a bounded DLPack CPU
  bridge. Ownership, mutability and lifetime checks remain explicit.
- Add compiler-generated guarded callback variants. Known callables enter precompiled
  specializations after an identity guard; other callables retain the generic path.
  This is ahead-of-time specialization, not online profiling or runtime code generation.
- Move nine numeric, range, text and conversion helpers into the Pystachy-compiled
  subset runtime while preserving their native ABI and effect contracts.
- Add opt-in LLVM line-table attribution, including deterministic metadata-ID
  remapping for sparse and boundary layouts.
- Add a small raylib-based GUI example with a headless regression path.

This alpha does not provide complete `ctypes`, DLPack, `copyreg` or GUI compatibility.
It retains the existing collector and shared-heap concurrency model, and does not
introduce native async, general threading or distributed compilation.
