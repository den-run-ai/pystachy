Pystachy compiles a statically typed subset of Python to native code through LLVM: `pystachy run`
for JIT execution, `pystachy build` for standalone executables. This second alpha collects about
200 pull requests merged since [v0.1.0-alpha.1](https://github.com/den-run-ai/pystachy/releases/tag/v0.1.0-alpha.1).
Strings now follow CPython's code-point semantics, and the release adds generators, `bytes`,
single inheritance, a native JSON prototype, faster regular expressions and about 20 more
standard-library modules. Pystachy remains experimental: it compiles a subset of Python, and
most PyPI packages do not compile unchanged.

## Highlights

- **Unicode strings.** `len()`, indexing, slicing and search offsets count code points over
  UTF-8 storage, with cached ASCII fast paths (#667). Empty-pattern `replace()` (#728),
  formatting widths and `expandtabs()` (#750), and the character counts that a UTF-8 text
  file's `write()` returns (#760) match CPython. `unicodedata` ports CPython's C module on the
  Unicode 15.1.0 tables (#576), and an opt-in
  [porting audit](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/docs/language/compatibility.md#text-and-file-positions)
  flags byte-oriented operations on non-ASCII text (#456).
- **Generators and context managers.** Generators run as LLVM coroutines, with `send()`,
  `throw()` and `close()` (#562, #572). `with` accepts class-based context managers, and
  `contextlib` provides `contextmanager`, `closing`, `nullcontext` and `suppress` (#572).
- **Classes and exceptions.** Ordinary single inheritance with runtime method dispatch (#379).
  Exception classes are values that can be kept, compared, called and raised (#721). Also new:
  `abc` (#551), enforced `__slots__` (#453, #459), read-only `@property` getters (#457) and
  `object()` sentinels (#718).
- **Binary data.** The `bytes` type, with literals, operations, methods and codecs (#534), plus
  `io.BytesIO` and `io.TextIOWrapper` (#598, #606).
- **Native JSON prototype.** `json.loads()` and `json.dumps()` handle recursive values (`None`,
  `bool`, `int`, `float`, `str`, lists and string-keyed dicts) in JIT and AOT programs, without
  CPython (#670, #722). It is bounded: 64-bit integers, nesting depth 256, string input, and no
  hooks or indentation. See its
  [scope](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/docs/json-prototype.md).
- **Typing and inference.** `typing.Any` in parameters, returns and initialized variables
  specializes to concrete types (#607, #629–#633). Explicit and inferred scalar unions (#393,
  #401–#408, #736–#738, #742). Generic templates, recursive call cycles and module attribute
  bindings are inferred and bound correctly in more programs (#413, #419, #425, #426, #439,
  #440, #449, #690, #755).
- **Interoperability.** Compiled programs can call Python packages through an embedded CPython
  (`lib/pyobj.py`, #170). `@extern` lends `list[float]` and `list[c_int64]` to C (#609), and
  `ffi.at` lends a list from an index (#699). The ndarray example gains optional CBLAS matrix
  products (#640).

## Libraries

New modules: `abc`, `atexit`, `binascii`, `codecs`, `contextlib`, `datetime`, `gettext`, `html`
(with `html.parser`), `itertools`, `json`, `keyword`, `opcode`, `random`, `shlex`, `struct`,
`token`, `types`, `unicodedata`, `warnings`, `weakref` and a one-thread `_thread`, plus
`collections.namedtuple()`. Experimental `_ast`, `_imp`, `_weakref` and `select.select`
prototypes back further imports, and `re` can use matchers generated for a program's own
patterns from a CPython profile (prototype, #740). The
[library guide](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/lib/README.md)
lists each module's supported APIs and limits.

## Performance

These are measurements of specific workloads, not a general speedup:

- An adapted [microGPT](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/bench/microgpt/README.md#measured-snapshot)
  trains for 100 steps 16.9× faster AOT than the original program on CPython (#639).
- [Native nanoGPT](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/examples/nanogpt/README.md#paired-measurement-after-the-array-and-blas-work)
  inference and training run without CPython, NumPy or PyTorch (#641, #642). On a
  108K-parameter float64 model with single-threaded OpenBLAS, AOT inference took 0.5–0.7× the
  latency of CPython + NumPy and 0.8–0.9× that of PyTorch.
- The three adapted pyperformance regex workloads were 2.5–2.7× slower than CPython. Their timed
  loops now take
  [0.32×, 0.44× and 0.82× CPython's time](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/docs/pyperformance.md#regex-in-place-subject-rerun)
  AOT (`regex_dna`, `regex_effbot`, `regex_v8`), after repeat-matcher, class-loop, prefilter
  and in-place subject changes (#676, #680, #682, #683, #685).
- On Linux the JIT loads its cached runtime as a shared library (#730). A warmed JIT run of
  `print(1)` took 37.3 ms instead of 58.6 ms, the medians of 15
  [paired runs](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/docs/reports/compatibility-updates.md#2026-10-19-field-alias-metadata-tuple-returns-and-shared-jit-runtime).
- Compiled code returns fixed tuples by value (#727), tags field accesses for alias analysis
  (#724), keeps local numeric unions unboxed (#742), repeats lists by doubling (#657), and
  keeps numeric list items and dict values out of the collector's scan (#603).

## Correctness

Fixed silent wrong results include AOT rounding of `float ** float` and `math.pow` (#735),
reads of conditional imports that had not run (#692), another module's attributes read through
the reading module's own bindings (#690) and empty-pattern string replacement (#728). Three
segfaults are fixed (#579). The parser now rejects what CPython's parser rejects, including a
backslash at the start of a line, bounds on `*Ts` and `**P`, `*` among other from-import names,
and invalid `match` patterns (#732).

## Verification

1,419 differential programs (776 in alpha.1) and 1,872 rejection tests (1,019 in alpha.1) run
through JIT and AOT with the CPython-hosted and self-compiled compilers. Each also runs with a
collection at every allocation, under UBSan, unoptimized and without Python on `PATH`. CI splits
them into groups that each target ten minutes or less, from one verified bootstrap (#741).
Publication now also requires the Packages workflow, and the archive and Docker smoke tests
cover the Linux JIT's shared runtime, a warm JIT run, a JSON round trip and Unicode indexing.

## Install

Native archives need LLVM to compile programs: LLVM 18 on Linux x86-64 (Ubuntu 24.04 or another
distribution with glibc 2.39+), LLVM 20 on macOS 15+ (arm64 or x86-64, with the Xcode Command
Line Tools). Built executables need neither Python nor LLVM, unless they embed CPython.

```sh
# Linux x86-64. On macOS: brew install llvm@20, use the macos-arm64 or macos-x86_64
# archive, and check it with shasum -a 256 -c.
sudo apt install clang-18 llvm-18 llvm-18-runtime
base=https://github.com/den-run-ai/pystachy/releases/download/v0.1.0-alpha.2
curl -LO "$base/pystachy-v0.1.0-alpha.2-linux-x86_64.tar.gz"
curl -LO "$base/pystachy-v0.1.0-alpha.2-linux-x86_64.tar.gz.sha256"
sha256sum -c pystachy-v0.1.0-alpha.2-linux-x86_64.tar.gz.sha256
tar -xzf pystachy-v0.1.0-alpha.2-linux-x86_64.tar.gz
pystachy-v0.1.0-alpha.2-linux-x86_64/bin/pystachy --version
```

The Docker image includes LLVM 18 and runs on linux/amd64:

```sh
docker run --rm dta67/pystachy:v0.1.0-alpha.2 --version
docker run --rm --user "$(id -u):$(id -g)" -v "$PWD:/work" dta67/pystachy:v0.1.0-alpha.2 run demo.py
```

Prereleases do not update `latest`. See the
[installation guide](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/docs/install.md)
for `PATH` setup, Docker on macOS and source builds.

## Known limitations

- Pystachy compiles a subset of Python. Multiple inheritance, `async`, `match`, `bytearray` and
  binary file I/O are unsupported. Integers are checked 64-bit values that raise
  `OverflowError`, Unicode case mapping is incomplete, and `Any` specializes to concrete types
  rather than adding dynamically typed storage.
- Most PyPI packages do not compile unchanged. The
  [15 third-party ports](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/ports/README.md)
  document their adaptations, library modules support the APIs their guide lists, and the JSON
  module is a bounded prototype.
- Compile-time diagnostics catch many, but not all, unsupported programs. Known differences from
  CPython are in the
  [compatibility reference](https://github.com/den-run-ai/pystachy/blob/v0.1.0-alpha.2/docs/language/compatibility.md).
- Packages are built for Linux x86-64, macOS arm64 and macOS x86-64; the Docker image is
  linux/amd64 only.
