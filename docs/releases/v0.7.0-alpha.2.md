Pystachy v0.7.0-alpha.2 adds an experimental WebAssembly target for Python snippets, reduces the number of modules that need dynamic `Any`, and adds a command for diagnosing local installations. LLVM remains the default native backend. Pystachy is an experimental compiler for a typed subset of Python.

## WebAssembly from a source checkout

- Build the shared runtime once. A Node host can compile a snippet once and run it repeatedly with fresh guest memory and a new set of tool callbacks each time. The direct backend reads finalized typed IR. When it encounters an unsupported operation, it reports the reason and can reuse the same compilation to build through LLVM/WASI. ([Wasm setup and examples](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.2/wasm/README.md), [#1641](https://github.com/den-run-ai/pystachy/pull/1641), [#1642](https://github.com/den-run-ai/pystachy/pull/1642))
- Both routes support Python exception handlers across calls. Generators and user-defined exception classes that need callback tables use the LLVM route. WASI error numbers can differ from Linux. Node's execution timeout covers instantiation and execution. Compilation and blocking native callbacks require separate supervision. ([#1652](https://github.com/den-run-ai/pystachy/pull/1652), [#1653](https://github.com/den-run-ai/pystachy/pull/1653))
- A complete typed IR text module can be read back into the same compiler and lowered to LLVM. The tool reports the state it cannot reconstruct, including extension entry points and LLVM debug line tables. ([#1636](https://github.com/den-run-ai/pystachy/pull/1636))

## Typing and runtime

- Closed unions support more arithmetic and container operations. `pathlib` and more of the JSON repair port compile without a module-level dynamic `Any` opt-in. Arithmetic-only parameters in eligible kernels keep their unboxed representation. ([#1632](https://github.com/den-run-ai/pystachy/pull/1632), [#1648](https://github.com/den-run-ai/pystachy/pull/1648), [#1650](https://github.com/den-run-ai/pystachy/pull/1650), [#1651](https://github.com/den-run-ai/pystachy/pull/1651))
- The IR verifier checks optional-value reads and accepts a dictionary length stored in an integer-or-string union. More fixed-width integer operations run in `runtime.py`, and percent-format padding passes typed settings. ([#1637](https://github.com/den-run-ai/pystachy/pull/1637), [#1649](https://github.com/den-run-ai/pystachy/pull/1649), [#1628](https://github.com/den-run-ai/pystachy/pull/1628), [#1647](https://github.com/den-run-ai/pystachy/pull/1647))

## Installation and limits

- Run `pystachy doctor` to inspect the LLVM tools and runtime cache. `pystachy --help` prints the available commands. A pre-commit hook checks staged Python files with Pystachy. ([#1640](https://github.com/den-run-ai/pystachy/pull/1640), [#1646](https://github.com/den-run-ai/pystachy/pull/1646), [#1645](https://github.com/den-run-ai/pystachy/pull/1645))
- The Linux source-build workflow checks glibc 2.28 on x86-64. The distributed Linux archives still require glibc 2.39+ and LLVM 18. The macOS archives require macOS 15+, Xcode Command Line Tools and LLVM 20. ([#1633](https://github.com/den-run-ai/pystachy/pull/1633), [installation](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.2/docs/install.md))
- The compiler GC stress test retains the 7,000-allocation interval. The verifier's allocation cost and outstanding Lean report rejections remain tracked. ([#1181](https://github.com/den-run-ai/pystachy/issues/1181), [#1644](https://github.com/den-run-ai/pystachy/issues/1644), [#1643](https://github.com/den-run-ai/pystachy/issues/1643))
