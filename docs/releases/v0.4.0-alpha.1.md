Pystachy v0.4.0-alpha.1 adds optional local job coordination and owned-buffer
examples, reduces CPython FFI wrapper bookkeeping, and introduces an experimental
temporary bootstrap tier. It includes the v0.3.1 correctness changes. Pystachy
remains an experimental compiler for a typed subset of Python.

## Local jobs and completion ownership

- Add an optional Linux application runner for independent executable jobs, with
  at most two workers, declared CPU/memory/input reservations, bounded captured
  output and finite deadlines of at most 900 seconds. Reservations remain held
  until the whole job tree finishes. Failure and cancellation stop admission and
  clean up owned descendants, including children forked during shutdown. Memory
  reservations are admission estimates, not enforced RSS limits.
  [Worker guide](https://github.com/den-run-ai/pystachy/blob/b69113429dd3e45581e5cbe957262a57bd4f67a2/tools/README.md#local-application-workers)
  · [#1153](https://github.com/den-run-ai/pystachy/pull/1153)
- Add an optional local CPU buffer example with copy, broadcast, all-gather and
  float64 sum operations across buffers in one process. Requests retain their
  storage and access leases until explicit completion acknowledgment. Checked
  views, cancellation and bounded request capacity make ownership visible to the
  caller; progress is explicit.
  [Buffer contract](https://github.com/den-run-ai/pystachy/blob/fedbfae45a326cab4c34f8e0732dba022534e5f5/examples/comm/README.md)
  · [#1150](https://github.com/den-run-ai/pystachy/pull/1150)
- Exercise that buffer API with an optional CPython coordinator running one or
  two real compiler IR/AOT jobs. Completion construction, transfer and decoding
  count toward job deadlines; admission slots remain reserved until acceptance.
  Handler output stays bounded through shutdown. Measurement manifests capture
  resolved workload imports, search choices and symlink targets, and reject
  changes detected after measurement.
  [Compiler example](https://github.com/den-run-ai/pystachy/blob/fedbfae45a326cab4c34f8e0732dba022534e5f5/examples/comm/dogfood.md)

The runners are CPython tools for local processes; children must remain in their
owned process groups. Compiler completion records travel through OS pipes; the
buffer operations themselves remain local. Buffer construction and readback use
copies across the Python/native boundary. The custom
buffer API and C interface are experimental. These examples add no shared-heap
threading, network backend or distributed execution to ordinary compiled programs.

## Compiler and development tooling

- Preserve inherited file descriptors during JIT and cached program launches.
  JIT inputs and cache locks use allocated descriptors, and deliberately closed
  standard streams remain closed. Add `os.set_inheritable` to the supported
  `os` subset.
  [Descriptor checks](https://github.com/den-run-ai/pystachy/blob/6f52de3602cd6a7f4e09747669b573634a8c3d21/tools/jitfdprobe.py)
  · [#1162](https://github.com/den-run-ai/pystachy/pull/1162)
- Reduce argument-binding and integer-list conversion work in the CPython FFI
  compatibility bridge. Complete positional calls use precomputed declaration
  metadata; keyword/default handling, validation, list aliasing and copy-back
  behavior are preserved. This changes the CPython wrapper, with performance
  evidence limited to its recorded workloads.
  [Scope and measurements](https://github.com/den-run-ai/pystachy/blob/904ca20de9a93d331799887c8480e7474811b3e6/bench/ffi_twin/README.md)
  · [#1159](https://github.com/den-run-ai/pystachy/pull/1159)
- Add opt-in `make BOOTSTRAP_AOT_OPT=1` for an O1 temporary first-stage compiler.
  The final compiler still uses O2, and all compiler/runtime fixed-point
  comparisons remain required. The default bootstrap remains O2. Changing the
  setting requires a clean build; lower tiers remain experimental and are not
  qualified for general application use.
  [Bootstrap settings](https://github.com/den-run-ai/pystachy/blob/d7dee32047481c4daacbed74fb13e930a1c15bd1/docs/internals.md#bootstrap-validation)
  · [#1160](https://github.com/den-run-ai/pystachy/pull/1160)
- Run two independent hosted lint control suites concurrently while preserving
  their checks and the existing limits of 20 PR jobs, two workers per task group
  and 15 minutes per job.
  [Lint runner](https://github.com/den-run-ai/pystachy/blob/1c0afdd3c2368185d2e028cf49a7c22baa8bdb47/tools/lint_controls.py)
  · [#1157](https://github.com/den-run-ai/pystachy/pull/1157)

- Separate full GC identity and JIT execution into dedicated CI jobs, preserving
  the complete corpus, runtime and syntax comparisons, and GC stress coverage.
  Every job remains limited to 15 minutes.
  [CI coverage](https://github.com/den-run-ai/pystachy/blob/v0.4.0-alpha.1/docs/testing.md#continuous-integration)

No release-wide compiler, application or bootstrap speedup is claimed. Optional
native I/O backends and restricted numerical parallelism remain separate work.
