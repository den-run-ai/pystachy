Pystachy v0.4.0-alpha.1 adds an optional local job runner and owned-buffer examples,
reduces CPython FFI wrapper bookkeeping and adds an experimental O1 bootstrap tier. It
includes the v0.3.1 correctness changes. Pystachy is an experimental compiler for a typed
subset of Python.

## Local jobs and buffers

- An optional Linux application runner executes independent jobs with at most two
  workers, declared CPU, memory and input reservations, bounded captured output and
  deadlines of at most 900 seconds. Reservations stay held until the whole job tree
  finishes, and failure or cancellation stops admission and cleans up owned descendants,
  including children forked during shutdown. Memory reservations are admission estimates,
  not enforced RSS limits.
  [Worker guide](https://github.com/den-run-ai/pystachy/blob/b69113429dd3e45581e5cbe957262a57bd4f67a2/tools/README.md#local-application-workers),
  [#1153](https://github.com/den-run-ai/pystachy/pull/1153)
- An optional local CPU buffer example provides copy, broadcast, all-gather and float64
  sum across buffers in one process. Requests keep their storage and access leases until
  the caller acknowledges completion; checked views, cancellation and bounded request
  capacity keep ownership visible, and progress is explicit.
  [Buffer contract](https://github.com/den-run-ai/pystachy/blob/fedbfae45a326cab4c34f8e0732dba022534e5f5/examples/comm/README.md),
  [#1150](https://github.com/den-run-ai/pystachy/pull/1150)
- An optional CPython coordinator uses that buffer API to run one or two real compiler IR
  or AOT jobs. Completion construction, transfer and decoding count toward job deadlines,
  admission slots stay reserved until acceptance, and handler output stays bounded through
  shutdown. Measurement manifests record resolved workload imports, search choices and
  symlink targets, and reject changes detected after measurement.
  [Compiler example](https://github.com/den-run-ai/pystachy/blob/fedbfae45a326cab4c34f8e0732dba022534e5f5/examples/comm/dogfood.md)

The runners are CPython tools for local processes, and children must stay in their owned
process groups. Compiler completion records travel through OS pipes; the buffer operations
stay local and copy data across the Python/native boundary for construction and readback.
The buffer API and its C interface are experimental. These examples add no shared-heap
threading, network backend or distributed execution to ordinary compiled programs.

## Compiler and tooling

- JIT and cached program launches preserve inherited file descriptors: JIT inputs and
  cache locks use allocated descriptors, and deliberately closed standard streams stay
  closed. `os.set_inheritable` joins the supported `os` subset.
  [Descriptor checks](https://github.com/den-run-ai/pystachy/blob/6f52de3602cd6a7f4e09747669b573634a8c3d21/tools/jitfdprobe.py),
  [#1162](https://github.com/den-run-ai/pystachy/pull/1162)
- The CPython FFI compatibility bridge does less argument-binding and integer-list
  conversion work: complete positional calls use precomputed declaration metadata, while
  keyword and default handling, validation, list aliasing and copy-back are unchanged.
  Performance evidence covers only the recorded workloads.
  [Scope and measurements](https://github.com/den-run-ai/pystachy/blob/904ca20de9a93d331799887c8480e7474811b3e6/bench/ffi_twin/README.md),
  [#1159](https://github.com/den-run-ai/pystachy/pull/1159)
- `make BOOTSTRAP_AOT_OPT=1` builds the temporary first-stage compiler at O1. The default
  bootstrap and the final compiler stay at O2, and every compiler and runtime fixed-point
  comparison still runs. Changing the setting needs a clean build; lower tiers are
  experimental and not qualified for general application use.
  [Bootstrap settings](https://github.com/den-run-ai/pystachy/blob/d7dee32047481c4daacbed74fb13e930a1c15bd1/docs/internals.md#bootstrap-validation),
  [#1160](https://github.com/den-run-ai/pystachy/pull/1160)

[compatibility](https://github.com/den-run-ai/pystachy/blob/v0.4.0-alpha.1/docs/language/compatibility.md)
and [changes since v0.3.1](https://github.com/den-run-ai/pystachy/compare/v0.3.1...v0.4.0-alpha.1).
