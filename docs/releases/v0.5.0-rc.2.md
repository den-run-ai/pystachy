Pystachy v0.5.0-rc.2 continues the frozen v0.5.0 feature set with a correction to star imports
and documentation of three known differences found while qualifying RC.1. Pystachy remains an
experimental compiler for a typed subset of Python. The features and earlier corrections are
described in the [RC.1 notes](https://github.com/den-run-ai/pystachy/releases/tag/v0.5.0-rc.1).

## Star imports

`from m import *` takes the `__all__` that a top-level `try` statement in `m` binds by leading
`__all__ = [...]` assignments, where nothing else in that statement rebinds it. Previously the
import ignored such an `__all__` and bound every public name, which could overwrite the importing
module's own names. An `__all__` bound in an `if` branch, or in a `try` statement in another way,
is still not seen. [#1513](https://github.com/den-run-ai/pystachy/issues/1513),
[star imports](https://github.com/den-run-ai/pystachy/blob/v0.5.0-rc.2/docs/language/modules.md#module-scope)

## Documentation

- The [compatibility reference](https://github.com/den-run-ai/pystachy/blob/v0.5.0-rc.2/docs/language/compatibility.md#modules-and-libraries)
  now lists three differences, each with a test that records the current behavior: a builtin's
  name bound at module level only on a path that does not run raises `NameError` when read
  ([#1512](https://github.com/den-run-ai/pystachy/issues/1512)); the conditional `__all__` cases
  above; and `except E as name`, where an import bound `name`, leaves the module bound after the
  handler ([#1514](https://github.com/den-run-ai/pystachy/issues/1514)).
- The typed IR reference gives the nine-word generator promise of programs that opt in to
  promoting ints, and the dynamic `Any` timing notes state a ratio that matches their own
  measurements. [#1334](https://github.com/den-run-ai/pystachy/issues/1334)

## Known limits

Dynamic `Any` and promoting integers remain experimental opt-ins. An optional import's handler
still does not catch an `ImportError` subclass in the cases that RC.1's notes list
([#1504](https://github.com/den-run-ai/pystachy/issues/1504)). `importlib.metadata`, async, full
native mypy, broad concurrency and new inference features remain outside v0.5.0. Release
candidates accept fixes within the frozen scope;
[#1476](https://github.com/den-run-ai/pystachy/issues/1476) tracks qualification and publication.

## Platforms

| Native archive | Requirements |
|---|---|
| Linux x86-64 / AArch64 | Ubuntu 24.04 or compatible glibc 2.39+ Linux; LLVM 18 |
| macOS arm64 / x86-64 | macOS 15+, Xcode Command Line Tools; LLVM 20 |

Archives and Docker run without Python; the hosted compiler needs Python 3.11+. Full
verification targets Linux x86-64 and ARM64 with CPython 3.13.16. Linux archives are not
manylinux packages. This prerelease keeps stable defaults at v0.4.0.
