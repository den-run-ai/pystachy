Pystachy v0.5.0-alpha.2 expands class typing and generic visitor support, shares method
dispatch across wide hierarchies, and reuses a precompiled runtime for ahead-of-time
builds. It includes the correctness repairs from alpha.1. Pystachy remains an experimental
compiler for a typed subset of Python.

## Class typing and constants

Classes in inheritance hierarchies can store annotated template objects, such as
`defaultdict[str, set[str]]`, without becoming class templates themselves. This also
applies transitively to classes named by their constructors' typed parameters. Those
classes need concrete field types; unrelated unused classes retain lazy validation.
[#1277](https://github.com/den-run-ai/pystachy/pull/1277),
[#1415](https://github.com/den-run-ai/pystachy/pull/1415),
[field rules](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.2/docs/language/typing.md#class-templates-and-generic-classes)

Ordinary module-level classes accept non-scalar `Final` values, such as
`FLAGS: Final = ["a", "b"]`, and initialized `ClassVar[T]` attributes. These extensions
exclude decorated classes and NamedTuples; `ClassVar` without an initializer remains
unsupported. `Final` still does not enforce immutability.
[#1280](https://github.com/den-run-ai/pystachy/pull/1280),
[#1281](https://github.com/den-run-ai/pystachy/pull/1281),
[annotations](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.2/docs/language/typing.md#annotations)

Later class-body values and method defaults can read earlier constants assigned once in
the same class. Lambda bodies and comprehension scopes after the first iterable retain
Python's separate scope rules.
[#1282](https://github.com/den-run-ai/pystachy/pull/1282),
[class attributes](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.2/docs/language/typing.md#fields-dataclasses-and-namedtuples)

## Generic visitors

A generic base without its own `__init__` supports concrete subclasses such as
`class TextVisitor(Visitor[str])`. A method with the signature
`accept(visitor: Visitor[T]) -> T` can infer its result from that concrete visitor,
including recursive calls and supported inherited classmethods.
[#1298](https://github.com/den-run-ai/pystachy/pull/1298),
[generic classes](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.2/docs/language/typing.md#explicit-generic-classes)

Generic bases whose constructors bind type variables remain unsupported as bases, as do
subclasses passing through their own type variables, such as `class Sub(Visitor[T])`.
A base-typed visitor variable still needs one compatible return type across its possible
implementations.

## Build performance

Eligible base-typed method calls in hierarchies with more than eight concrete classes
share generated dispatchers, reducing repeated code at call sites. Generators, inferred
return types and other context-dependent calls retain their existing dispatch paths.
[#1274](https://github.com/den-run-ai/pystachy/pull/1274),
[dispatch rules](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.2/docs/internals.md#frontend-and-specialization)

`pystachy build` caches a precompiled runtime and links it into later executables,
avoiding repeated runtime optimization and code generation. AddressSanitizer builds,
uncached runtimes and failed preparation use the existing bitcode path. Integration
also preserves valid inputs when only part of the runtime cache can be published.
[#1377](https://github.com/den-run-ai/pystachy/pull/1377),
[runtime caching](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.2/docs/internals.md#jit-aot-and-runtime-caching)

Three paired local Linux x86-64 measurements with LLVM 18.1.3, warm runtime caches
and the program cache disabled show shorter builds with larger executables:

| Workload | Alpha.1 build | Alpha.2 build | Executable growth |
|---|---:|---:|---:|
| Numeric | 1.439 s | 0.448 s | 35.6% |
| JSON | 12.758 s | 9.861 s | 4.9% |
| Float copying | 2.183 s | 0.311 s | 34.5% |

A separate six-pair JSON control used equal-length source paths, CPU affinity and
600,000 iterations. Loop medians changed by +0.17% in JIT and -0.95% in AOT, with
overlapping ranges. These measurements establish neither a sustained JSON slowdown
nor a general execution-speed improvement. Application build time, executable size
and runtime should be measured separately.
[Measurements and limits](https://github.com/den-run-ai/pystachy/pull/1488#issuecomment-6875913105)

## Known limits and platforms

Dynamic `Any` and promoting integers remain experimental opt-ins. Async, full native
mypy, broader numeric types and experimental concurrency remain outside this alpha.
[Compatibility](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.2/docs/language/compatibility.md)

Native archives target Linux x86-64/AArch64 with glibc 2.39+ and LLVM 18, and macOS
arm64/x86-64 with macOS 15+, Xcode Command Line Tools and LLVM 20. Linux archives
are not manylinux packages. Archives and Docker run without Python; the hosted compiler
needs Python 3.11+. Prereleases leave stable `latest` unchanged.
