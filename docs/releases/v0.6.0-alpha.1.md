Pystachy v0.6.0-alpha.1 starts the v0.6.0 series from v0.5.0. It infers more field and
annotation types in code like mypy's, matches sequence patterns on lists, adds standard
library modules and functions, and repairs comparisons of class unions and paths with
non-ASCII characters. Pystachy remains an experimental compiler for a typed subset of Python.

## Typing and field inference

- Fields take their types from `and` and `or` operands, `any()`, `all()` and other `bool`
  builtins, comprehensions, attribute chains, `set()` and `frozenset()` calls, and tuple
  targets that no plain assignment of the field contradicts. Property getters without a
  return annotation infer one.
  ([#1286](https://github.com/den-run-ai/pystachy/pull/1286),
  [#1384](https://github.com/den-run-ai/pystachy/pull/1384),
  [#1376](https://github.com/den-run-ai/pystachy/pull/1376),
  [#1374](https://github.com/den-run-ai/pystachy/pull/1374),
  [#1364](https://github.com/den-run-ai/pystachy/pull/1364))
- Annotations read `Literal[...]` as the type of its values, `TypeGuard` and `TypeIs` as
  `bool`, and classes that only `TYPE_CHECKING` imports. `typing.NewType` compiles as an
  alias whose calls return their argument, and `x: dict[K, V] = defaultdict(...)` keeps the
  `defaultdict`.
  ([#1454](https://github.com/den-run-ai/pystachy/pull/1454),
  [#1378](https://github.com/den-run-ai/pystachy/pull/1378),
  [#1317](https://github.com/den-run-ai/pystachy/pull/1317),
  [#1355](https://github.com/den-run-ai/pystachy/pull/1355),
  [#1402](https://github.com/den-run-ai/pystachy/pull/1402))
- After `isinstance(x, (A, B))`, a function that calls a method that `A` and `B` define,
  and their base does not, narrows `x` to `A | B`; elsewhere `x` keeps its type and
  compiles as before. `isinstance()` takes the `collections` mappings for dicts, and class
  attributes and class methods are readable through `Any`.
  ([#1379](https://github.com/den-run-ai/pystachy/pull/1379),
  [#1401](https://github.com/den-run-ai/pystachy/pull/1401),
  [#1423](https://github.com/den-run-ai/pystachy/pull/1423))
- An abstract `@contextmanager` method compiles, and calling it raises as in CPython.
  Re-exported constants are readable during circular imports.
  ([#1466](https://github.com/den-run-ai/pystachy/pull/1466),
  [#1359](https://github.com/den-run-ai/pystachy/pull/1359))

## Pattern matching

Sequence patterns match list subjects and take a starred name or `*_`. With `*_`, each other
item is read once, just before its subpattern, as CPython reads it.
([#1345](https://github.com/den-run-ai/pystachy/pull/1345),
[semantics](https://github.com/den-run-ai/pystachy/blob/v0.6.0-alpha.1/docs/language/semantics.md))

## Standard library

- `sysconfig` gives the Pystachy home's variables and paths, `platform` gives `uname()`
  and the Python version, and `importlib.metadata` reads the versions and metadata of the
  distributions on the module path.
  ([#1371](https://github.com/den-run-ai/pystachy/pull/1371),
  [#1356](https://github.com/den-run-ai/pystachy/pull/1356),
  [#1438](https://github.com/den-run-ai/pystachy/pull/1438))
- `base64` encodes and decodes `bytes`, `functools.cached_property` and
  `contextlib.ExitStack` are available, and modules have `__file__`.
  ([#1433](https://github.com/den-run-ai/pystachy/pull/1433),
  [#1471](https://github.com/den-run-ai/pystachy/pull/1471),
  [#1347](https://github.com/den-run-ai/pystachy/pull/1347),
  [#1464](https://github.com/den-run-ai/pystachy/pull/1464))
- `platform.uname()` has five items where CPython 3.13's has six, and `dir()` lists the
  names that `@cached_property` adds.
  ([library compatibility](https://github.com/den-run-ai/pystachy/blob/v0.6.0-alpha.1/lib/compatibility.md))

## Correctness repairs

- `==` and `!=` of a value of a union of classes, such as a parameter annotated `A | B`,
  and an object compare the object, by its class's `__eq__` or by identity. v0.5.0
  compared the union's box and could print `False` where CPython prints `True`.
  ([repair](https://github.com/den-run-ai/pystachy/commit/20e1ff25b9d849b50067c704248921b14dcbc7f4))
- Paths from the host reach programs as UTF-8, so `sys.prefix`, `__file__` and
  `importlib.metadata`'s search path work in directories named with non-ASCII characters.
  ([#1517](https://github.com/den-run-ai/pystachy/issues/1517))

## Known limits and platforms

Dynamic `Any` and promoting integers remain experimental opt-ins. Mapping patterns, async,
full native mypy and broad concurrency are outside this alpha. The
[compatibility reference](https://github.com/den-run-ai/pystachy/blob/v0.6.0-alpha.1/docs/language/compatibility.md)
lists the documented deviations.

| Native archive | Requirements |
|---|---|
| Linux x86-64 / AArch64 | Ubuntu 24.04 or compatible glibc 2.39+ Linux; LLVM 18 |
| macOS arm64 / x86-64 | macOS 15+, Xcode Command Line Tools; LLVM 20 |

Archives and Docker run without Python; the hosted compiler needs Python 3.11+ and reports
`commit unknown` when installed with pip. Full verification targets Linux x86-64 and ARM64
with CPython 3.13.16. Linux archives are not manylinux packages. Prereleases leave the
stable `latest` unchanged.
