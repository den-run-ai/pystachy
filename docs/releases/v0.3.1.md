Pystachy v0.3.1 fixes bounded text reads on live pipes and improves compiler
build tooling and package validation. Pystachy remains an experimental compiler
for a typed subset of Python.

- Return from `read(0)` without waiting for input and from bounded text reads
  after the requested complete UTF-8 or Latin-1 characters. Preserve required
  universal-newline carriage-return lookahead.
- Retain raw build IR for bootstrap fixed-point checks, avoiding two redundant
  compiler frontend runs without changing the checked compiler/runtime outputs.
- Add opt-in compiler stage timing and Linux C-runtime bitcode caching across
  compiler rebuilds. Cache keys include source, flags and toolchain identity;
  ineligible builds or invalid entries fall back to ordinary compilation.
- Avoid temporary buffers for eligible terminated float strings while preserving
  parsing results and fallback behavior.
- Validate the JSON-repair companion wheel in a clean installation, including
  native ABI, API/CLI output, GC and worker/thread controls.
- Add optional LLVM optimization correctness probes and refresh development
  tooling and CI actions.

Native worker, communication-buffer and networking prototypes remain outside
this release. C-runtime caching remains opt-in.
