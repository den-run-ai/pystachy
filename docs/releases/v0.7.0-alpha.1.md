Pystachy v0.7.0-alpha.1 starts the v0.7.0 series from v0.6.1. It compiles nested and local
classes, subclasses of `list`, `dict` and `collections.abc` classes, and classes with
`__getattr__`; accepts an `int` where `float` is annotated; fills in most of `enum`; and
makes the typed IR a checked text form with source locations. Pystachy remains an
experimental compiler for a typed subset of Python.

## Classes

- A class statement in a class body, or in a function that runs at most once, makes a class
  with CPython's `__qualname__`.
  ([#1596](https://github.com/den-run-ai/pystachy/pull/1596),
  [#1613](https://github.com/den-run-ai/pystachy/pull/1613))
- A class may derive from `list`, `list[T]`, `dict` or `dict[K, V]` as its one base; what it
  leaves to the builtin compiles to the builtin's own code, `__missing__` included.
  ([#1558](https://github.com/den-run-ai/pystachy/pull/1558))
- A class may derive from `collections.abc` classes such as `MutableMapping`, `Sequence`
  and `Set`, which inherit CPython's mixin methods, and `isinstance()` takes ABCs such as
  `Sized`, `Iterable` and `Hashable`.
  ([#1610](https://github.com/den-run-ai/pystachy/pull/1610))
- A class's `__getattr__` is called for the attributes its objects lack, and a secondary
  base's `__init__` may store attributes.
  ([#1559](https://github.com/den-run-ai/pystachy/pull/1559),
  [#1614](https://github.com/den-run-ai/pystachy/pull/1614))
- Using a new object of an abstract class in the same expression, as `print(Half())` does,
  raises CPython's `TypeError`, where the compiler failed.
  ([#1621](https://github.com/den-run-ai/pystachy/pull/1621))

## Typing and library

- A variable, field or return annotated `float` holds an `int` it is given, as PEP 484
  allows, and one annotated `int` or `str` holds an `IntEnum`, `IntFlag` or `StrEnum`
  member as it is.
  ([#1550](https://github.com/den-run-ai/pystachy/pull/1550),
  [#1592](https://github.com/den-run-ai/pystachy/pull/1592))
- `enum` adds `member()`, `nonmember()`, `@verify(...)` with its checks, flags' `boundary=`
  (`STRICT`, `CONFORM`, `KEEP`), `show_flag_values()`, the `global_*()` helpers and the
  functional API at the top of a module.
  ([#1563](https://github.com/den-run-ai/pystachy/pull/1563))
- With dynamic `Any`, `deque`, `bytearray`, `weakref.ref`, `MappingProxyType` and the
  `collections` mappings compare with other types as CPython's do.
  ([#1599](https://github.com/den-run-ai/pystachy/pull/1599))

## Typed IR and tools

- With `PYSTACHY_IRCHECK=1`, the typed IR verifier checks each operand against its value's
  type, and a value read at another type is an explicit `cast` op; the Lean shape check
  proves that each value is defined before it is read. Every op records its source line, and
  a module prints as text with its classes and their fields.
  ([typed IR](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.1/docs/typed-ir.md),
  [#1593](https://github.com/den-run-ai/pystachy/pull/1593),
  [#1566](https://github.com/den-run-ai/pystachy/pull/1566),
  [#1604](https://github.com/den-run-ai/pystachy/pull/1604),
  [#1606](https://github.com/den-run-ai/pystachy/pull/1606),
  [#1617](https://github.com/den-run-ai/pystachy/pull/1617),
  [#1625](https://github.com/den-run-ai/pystachy/pull/1625))
- `tools/annotate_ir.py` shows each source line with its typed IR and LLVM IR, and
  `tools/rejection_survey.py` lists several rejections of a program in one run.
  ([#1565](https://github.com/den-run-ai/pystachy/pull/1565),
  [#1549](https://github.com/den-run-ai/pystachy/pull/1549))
- The hosted compiler is checked under CPython 3.11 to 3.15, and 13 more pyperformance
  benchmarks are ported (38 of 52).
  ([#1626](https://github.com/den-run-ai/pystachy/pull/1626),
  [#1619](https://github.com/den-run-ai/pystachy/pull/1619))

## Known limits and platforms

Dynamic `Any` and promoting integers remain experimental opt-ins. The known issues of v0.6.1
remain ([#1512](https://github.com/den-run-ai/pystachy/issues/1512),
[#1513](https://github.com/den-run-ai/pystachy/issues/1513),
[#1514](https://github.com/den-run-ai/pystachy/issues/1514),
[#1602](https://github.com/den-run-ai/pystachy/issues/1602)). The
[compatibility reference](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.1/docs/language/compatibility.md)
lists the limits of the new class features and the documented deviations.

| Native archive | Requirements |
|---|---|
| Linux x86-64 / AArch64 | Ubuntu 24.04 or compatible glibc 2.39+ Linux; LLVM 18 |
| macOS arm64 / x86-64 | macOS 15+, Xcode Command Line Tools; LLVM 20 |

Archives and Docker run without Python; the hosted compiler needs Python 3.11+ and reports
`commit unknown` when installed with pip. Full verification targets Linux x86-64 and ARM64
with CPython 3.13.16. Linux archives are not manylinux packages. Prereleases leave the
stable `latest` unchanged.
