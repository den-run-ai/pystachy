These are unpublished preparation notes. The planned `v0.2.1` version was not
tagged or published. See the subsequent
[v0.3.0-alpha.1](https://github.com/den-run-ai/pystachy/releases/tag/v0.3.0-alpha.1)
and [v0.3.0](https://github.com/den-run-ai/pystachy/releases/tag/v0.3.0) releases.

The plan covered value preservation, verification and packaging for Pystachy's
typed subset of Python.

## Correctness and runtime

- Fresh tuples destined for dynamic `Any` preserve optional numeric identity and
  avoid premature 64-bit overflow for optional promoting integers. Existing
  typed-tuple boundaries remain documented
  ([tuple fix](https://github.com/den-run-ai/pystachy/pull/1132)).
- JSON repair preserves unquoted multilingual content. Five string predicates
  use Unicode 15.1 classification; the API replay expands from 645 to 837 cases.
  Unicode case mapping remains separate
  ([Unicode fix](https://github.com/den-run-ai/pystachy/pull/1109)).
- Text reads and newline handling retain their inline byte paths after the
  read-error fix, preserving EOF, error and interrupted-read behavior. An LLVM
  IR check guards against the per-byte call regression
  ([text reads](https://github.com/den-run-ai/pystachy/pull/1098)).

## Verification and distribution

- Example benchmarks fail on incorrect output, failed builds, invalid reports
  and subprocess timeouts. Verification includes 24 real command-line cases
  and the existing JSON-repair and HTTP checks
  ([validation](https://github.com/den-run-ai/pystachy/pull/1101)).
- PR verification checks the exact event merge and head. A stale base in the
  event selects code verification against the tested merge's actual parent.
- LLVM provisioning retries selected transient HTTP failures and timeouts while
  retaining checksum checks and immediate failure for permanent errors
  ([provisioning](https://github.com/den-run-ai/pystachy/pull/1100)).
- Release tooling supports publishing verified source packages to PyPI, with
  source/version checks and isolated package validation before upload
  ([publishing](https://github.com/den-run-ai/pystachy/pull/1124)).
- Reference and example guides are refreshed, benchmark provenance remains
  linked, and the README highlights PyPI and Docker installation.

Dynamic `Any` and promoting integers remain experimental and opt-in. See the
[compatibility guide](https://github.com/den-run-ai/pystachy/blob/v0.3.0-alpha.1/docs/language/compatibility.md)
for supported behavior and remaining limits. The planned scope retained the
collector and excluded general threading and distributed execution.
