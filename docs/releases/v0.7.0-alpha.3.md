Pystachy v0.7.0-alpha.3 makes compiled executables print CPython-style tracebacks. It extends class templates and closed unions, and lets the experimental WebAssembly backend compile generators and callbacks directly. This is the last alpha of 0.7.0: its release candidates take fixes only. LLVM remains the default native backend. Pystachy is an experimental compiler for a typed subset of Python.

## Errors and the command line

- An uncaught exception in an executable prints a traceback with the file, line and function of each frame, as CPython does. `build` now gives a program's functions line tables, which the traceback reads; `PYSTACHY_DEBUG_LINES=0` leaves them out. Chained exceptions, macOS and Wasm still print only the final line. ([#1710](https://github.com/den-run-ai/pystachy/pull/1710), [errors and cleanup](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.3/docs/internals.md#errors-and-cleanup))
- `pystachy check --semantic FILE.py` compiles a file without LLVM and reports its first error. `pystachy build` accepts `-O0`, `-O1`, `-O2` and `-g` after the source file. `pystachy doctor` prints the runtime cache as an absolute path. The getting-started guide lists valid source that the pre-commit hook rejects. ([#1693](https://github.com/den-run-ai/pystachy/pull/1693), [#1694](https://github.com/den-run-ai/pystachy/pull/1694), [#1691](https://github.com/den-run-ai/pystachy/pull/1691), [#1690](https://github.com/den-run-ai/pystachy/pull/1690))

## Typing and libraries

- A class can derive from a specialization of a class template, with a templated `__init__` and template-typed fields. A closed union can hold one tuple type, and recursive aliases are named by their shape and type arguments. ([#1707](https://github.com/den-run-ai/pystachy/pull/1707), [#1716](https://github.com/den-run-ai/pystachy/pull/1716), [#1698](https://github.com/den-run-ai/pystachy/pull/1698), [#1699](https://github.com/den-run-ai/pystachy/pull/1699), [typing](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.3/docs/language/typing.md))
- `==` between an object and a value of another type calls the left operand's `__eq__`, then the reflected one, then compares identity, as CPython does. ([#1706](https://github.com/den-run-ai/pystachy/pull/1706))
- Enum classes held in class attributes, `sys.float_info` attributes in class bodies, and `typing.Pattern[str]`, `Match[str]` and `IO[str]` annotations compile. `zlib.crc32()` and `zlib.adler32()` are available. ([#1686](https://github.com/den-run-ai/pystachy/pull/1686), [#1665](https://github.com/den-run-ai/pystachy/pull/1665), [#1674](https://github.com/den-run-ai/pystachy/pull/1674), [#1687](https://github.com/den-run-ai/pystachy/pull/1687), [#1668](https://github.com/den-run-ai/pystachy/pull/1668))
- Fixes: star imports follow a conditional `__all__` and a package's current exports. `abs()` of a nonnegative integer keeps its identity. Chained `__class__()` constructors compile in linear rather than exponential time. The `threading` port releases discarded `Thread` objects. ([#1669](https://github.com/den-run-ai/pystachy/pull/1669), [#1684](https://github.com/den-run-ai/pystachy/pull/1684), [#1688](https://github.com/den-run-ai/pystachy/pull/1688), [#1664](https://github.com/den-run-ai/pystachy/pull/1664), [#1682](https://github.com/den-run-ai/pystachy/pull/1682))

## WebAssembly from a source checkout

- The direct backend compiles typed callbacks and plain generators, keeps a generator's typed state across suspension, and dispatches static object callbacks through the module's table. Builtin container subclasses get wasm32 header layouts. ([#1675](https://github.com/den-run-ai/pystachy/pull/1675), [#1676](https://github.com/den-run-ai/pystachy/pull/1676), [#1678](https://github.com/den-run-ai/pystachy/pull/1678), [#1679](https://github.com/den-run-ai/pystachy/pull/1679), [#1680](https://github.com/den-run-ai/pystachy/pull/1680), [#1683](https://github.com/den-run-ai/pystachy/pull/1683), [Wasm setup](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.3/wasm/README.md))
- Fixes under WASI: nested handlers unwind to the enclosing one, and `*args` tuples and `vars()` fields keep the wasm32 layout. The collector traces whole pointer words, and zero-length writes no longer move file positions. `float("-nan")` and `math.fma` keep their signs. The Wasmtime runner forwards piped input, and `WASM_EH=standard` builds enable the reference types that Binaryen's exception conversion needs. `wasm/check_corpus.py` compares the corpus with a list of explained differences. ([#1695](https://github.com/den-run-ai/pystachy/pull/1695), [#1696](https://github.com/den-run-ai/pystachy/pull/1696), [#1677](https://github.com/den-run-ai/pystachy/pull/1677), [#1705](https://github.com/den-run-ai/pystachy/pull/1705), [#1708](https://github.com/den-run-ai/pystachy/pull/1708), [#1709](https://github.com/den-run-ai/pystachy/pull/1709), [#1681](https://github.com/den-run-ai/pystachy/pull/1681), [#1697](https://github.com/den-run-ai/pystachy/pull/1697))

## Verification

- Typed IR text carries a format version. With `PYSTACHY_IRCHECK=1`, the verifier also checks that control flow is structured and proves reads of objects at narrower classes. ([#1700](https://github.com/den-run-ai/pystachy/pull/1700), [#1701](https://github.com/den-run-ai/pystachy/pull/1701), [#1702](https://github.com/den-run-ai/pystachy/pull/1702), [#1704](https://github.com/den-run-ai/pystachy/pull/1704))
- The compiler infers its own types in one attempt, which the bootstrap now requires. Each dynamic `Any` opt-in in the library is recorded as a contract or as tracked debt. ([#1714](https://github.com/den-run-ai/pystachy/pull/1714), [#1713](https://github.com/den-run-ai/pystachy/pull/1713), [dynamic Any boundaries](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.3/docs/dynamic-any-boundaries.md))

## Installation and limits

- Supported platforms are unchanged from alpha.2. The distributed Linux archives require glibc 2.39+ and LLVM 18. The macOS archives require macOS 15+, Xcode Command Line Tools and LLVM 20. ([installation](https://github.com/den-run-ai/pystachy/blob/v0.7.0-alpha.3/docs/install.md))
- Objects of a class template, and of a subclass of one, keep reading a class attribute's original value after the program rebinds it through the class's name; a release candidate will fix this. ([#1724](https://github.com/den-run-ai/pystachy/issues/1724))
- Moving the list and string core into `runtime.py`, `Protocol` and `object` storage, and the portable LLVM download wait for 0.8.0. The verifier's allocation cost under GC stress and the remaining Lean report rejections are still tracked. ([#1644](https://github.com/den-run-ai/pystachy/issues/1644), [#1643](https://github.com/den-run-ai/pystachy/issues/1643))
