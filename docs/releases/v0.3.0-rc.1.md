This release candidate freezes the combined v0.3.0 alpha feature set for final
validation. The compiler remains experimental.

- Compiler foundations retain richer list semantics, reduce selected allocations
  and LLVM text construction, and cache eligible native Linux ORC programs.
- Bounded class/reducer workflows, static ctypes declarations and retained CPU
  buffers extend interoperability. The optional DLPack bridge uses NumPy in the
  CPython host.
- Guarded callbacks select precompiled variants with a generic fallback. Nine
  runtime helpers use the compiled Python subset, and source-line attribution is
  opt-in.
- Byte-BPE, dense-ID filtering and a small raylib GUI provide practical examples.

No new feature work is included after the alpha.2 freeze. Final qualification
covers compatibility, compiler/runtime fixed points, GC and native lifetimes,
ABI/FFI, caches, installation and representative applications on the release
revision. Results from earlier revisions remain historical evidence.

The existing collector and concurrency model are retained. These bounded APIs
do not establish complete ctypes, DLPack, copyreg or GUI compatibility, general
threading, native async or distributed execution.

See the [compatibility guide](https://github.com/den-run-ai/pystachy/blob/v0.3.0-rc.1/docs/language/compatibility.md)
and [installation instructions](https://github.com/den-run-ai/pystachy/blob/v0.3.0-rc.1/docs/install.md).
