Pystachy v0.5.0-rc.1 freezes the v0.5.0 feature set for final qualification. Since alpha.5,
it corrects tuple searches for promoting integers, lets optional-import handlers catch
subclasses of `ImportError`, and removes contradictions from the documentation. It remains an
experimental compiler for a typed subset of Python.

## Corrections since alpha.5

- Under `# pystachy: python-int`, a tuple's `in`, `not in`, `count()` and `index()` compare a
  promoting integer with items of a closed union, such as `int | str | None`, in either
  direction. Previously `key in ("one", 1, 2.5)` returned `False` for a `key` of that type
  holding `1`. An integer past 64 bits equals only a float of the same value.
  [#1506](https://github.com/den-run-ai/pystachy/pull/1506)
- An optional import keeps its `except` clauses for the statements after its resolved imports
  when the program defines a subclass of `ImportError` and those statements may raise. The
  handler now catches the subclass, as in CPython, instead of the program ending.
  [#1511](https://github.com/den-run-ai/pystachy/pull/1511),
  [optional imports](https://github.com/den-run-ai/pystachy/blob/v0.5.0-rc.1/docs/language/modules.md#optional-imports)
- The documentation agrees with itself and the compiler on the supported macOS version,
  `Exception | None`, unannotated `__len__` methods, `bytes` dictionary keys and the list of
  shipped modules. [#1507](https://github.com/den-run-ai/pystachy/pull/1507)

The subclass still ends the program where the `try` statement is in a class body; where the
handler or those statements define a function or class, import a module, or rebind an imported,
builtin or dunder name; where the program does not compile with the clauses kept; and where an
imported module's own code raises it. Programs that define no such subclass compile as before.

## Features carried from the alphas

- **Classes and generics:** annotated template fields in class hierarchies, non-scalar `Final`
  and initialized `ClassVar` attributes, class-body constants, generic visitors such as
  `class TextVisitor(Visitor[str])`, and constructors specialized per fixed class layout.
  [Alpha.2](https://github.com/den-run-ai/pystachy/releases/tag/v0.5.0-alpha.2),
  [alpha.4](https://github.com/den-run-ai/pystachy/releases/tag/v0.5.0-alpha.4)
- **Numbers and keys:** numeric conversion and reflected-operator protocols, comparison methods
  that return `NotImplemented`, complex numbers, a bounded `decimal` module, and `None`,
  optional, runtime-length tuple and class-union keys.
  [Alpha.3](https://github.com/den-run-ai/pystachy/releases/tag/v0.5.0-alpha.3)
- **Library and tests:** `hashlib` (MD5, SHA-1, SHA-224 and SHA-256), `hmac` with
  `compare_digest()`, and native pytest failure explanations with node-ID selection.
  [Alpha.4](https://github.com/den-run-ai/pystachy/releases/tag/v0.5.0-alpha.4)
- **Compiler and builds:** six explicit compiler stages ending at an inspectable, finalized
  typed IR; shared dispatchers for wide class hierarchies; and a cached precompiled runtime for
  ahead-of-time builds.
  [Alpha.2](https://github.com/den-run-ai/pystachy/releases/tag/v0.5.0-alpha.2),
  [alpha.5](https://github.com/den-run-ai/pystachy/releases/tag/v0.5.0-alpha.5)
- **Earlier repairs:** tuple searches through runtime subclasses and class unions, and
  cross-module `super()` calls to context-manager methods.
  [Alpha.1](https://github.com/den-run-ai/pystachy/releases/tag/v0.5.0-alpha.1)

## Known limits

Dynamic `Any` and promoting integers remain experimental opt-ins. Known issues include reads of
a builtin's name where a module global of that name is unbound
([#1512](https://github.com/den-run-ai/pystachy/issues/1512)), star imports from a module that
binds `__all__` inside `try` or `if` ([#1513](https://github.com/den-run-ai/pystachy/issues/1513))
and the optional-import cases above. See the
[compatibility reference](https://github.com/den-run-ai/pystachy/blob/v0.5.0-rc.1/docs/language/compatibility.md).

`importlib.metadata`, async, full native mypy, broad concurrency and new inference features remain
outside v0.5.0. Release candidates accept fixes within the frozen scope;
[#1476](https://github.com/den-run-ai/pystachy/issues/1476) tracks qualification and publication.

## Platforms

| Native archive | Requirements |
|---|---|
| Linux x86-64 / AArch64 | Ubuntu 24.04 or compatible glibc 2.39+ Linux; LLVM 18 |
| macOS arm64 / x86-64 | macOS 15+, Xcode Command Line Tools; LLVM 20 |

Archives and Docker run without Python; the hosted compiler needs Python 3.11+. Full
verification targets Linux x86-64 and ARM64 with CPython 3.13.16. Linux archives are not
manylinux packages. This prerelease keeps stable defaults at v0.4.0.
