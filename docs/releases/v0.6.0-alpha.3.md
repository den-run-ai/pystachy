Pystachy v0.6.0-alpha.3 is the last alpha of v0.6.0. It adds `pprint`, `inspect`,
`subprocess`, `importlib.resources`, `concurrent.futures`, `gc` and `bytearray`, lets an
`int` argument reach a `float` parameter, runs `unittest` suites natively, makes string case
methods and numeric paths faster, and restructures the typed IR. Pystachy remains an
experimental compiler for a typed subset of Python.

## Standard library

- `pprint` formats with every option CPython's has, choosing the layout by a value's static
  type; objects of classes print as their `repr()`.
  ([#1344](https://github.com/den-run-ai/pystachy/pull/1344))
- `inspect` gives `Parameter`, `Signature` and `cleandoc()`. `subprocess` gives `run()`,
  `call()`, `check_call()`, `check_output()`, `getoutput()` and `Popen` over fork and exec.
  `importlib` adds `resources`, `util.resolve_name()` and `import_module()` of a constant
  name. ([#1417](https://github.com/den-run-ai/pystachy/pull/1417),
  [#1385](https://github.com/den-run-ai/pystachy/pull/1385),
  [#1365](https://github.com/den-run-ai/pystachy/pull/1365),
  [#1474](https://github.com/den-run-ai/pystachy/pull/1474))
- `concurrent.futures` runs a `ThreadPoolExecutor` on the program's one thread: `submit()`
  runs the call before it returns. `gc.collect()` runs the collector, and the module keeps
  its other settings. ([#1416](https://github.com/den-run-ai/pystachy/pull/1416),
  [#1351](https://github.com/den-run-ai/pystachy/pull/1351))
- `functools.total_ordering` adds the ordering methods a class lacks, from the ones it
  defines or inherits, as CPython does.
  ([#1473](https://github.com/den-run-ai/pystachy/pull/1473))
- For mypy's own code, `librt.base64` and `ast_serialize`, mypy's parser front end, give the
  results and errors of their C and Rust extensions.
  ([#1434](https://github.com/den-run-ai/pystachy/pull/1434),
  [#1435](https://github.com/den-run-ai/pystachy/pull/1435))

## Language and types

- `bytearray` is a class of the subset: mutable bytes with indexing, slicing, slice
  assignment and deletion, and the methods that change it in place.
  ([#1478](https://github.com/den-run-ai/pystachy/pull/1478))
- An `int` or `bool` argument may reach a `float` parameter of a function called directly,
  which compiles again for it. Its body computes with `int` operations, as CPython's does,
  under Pystachy's integer limits: a result past 64 bits raises `OverflowError`, and an
  `int` to a negative `int` power raises `ValueError`.
  ([#1533](https://github.com/den-run-ai/pystachy/pull/1533))
- `%` formats a mapping through `%(name)s` conversions, and `in` on a dict's `keys()` or
  `items()`, and comparisons of two such views, behave as sets.
  ([#1479](https://github.com/den-run-ai/pystachy/pull/1479),
  [#1256](https://github.com/den-run-ai/pystachy/pull/1256))
- An optional import's handler runs where an imported module fails at its own import of a
  missing module, as `ssl` does without `_ssl`.
  ([#1424](https://github.com/den-run-ai/pystachy/pull/1424))
- Fields take their types from sets of one type and from other classes' attributes,
  `tuple()` takes sets and dicts, tab indentation follows CPython's tokenizer, and a
  dynamic-`Any` display may read a name that an earlier item's `:=` binds.
  ([#1388](https://github.com/den-run-ai/pystachy/pull/1388),
  [#1405](https://github.com/den-run-ai/pystachy/pull/1405),
  [#1343](https://github.com/den-run-ai/pystachy/pull/1343))

## Testing

The native pytest runner runs `unittest.TestCase` classes, test packages with layered
`conftest.py` files, marks, `-k` and `-m`, fixture scopes and parameters, `tmp_path`,
`capsys`, `capfd` and `monkeypatch`. It reports a test it cannot compile and leaves it out.
([#1287](https://github.com/den-run-ai/pystachy/pull/1287))

## Performance

- `str`'s case methods and character tests read generated Unicode tables directly, taking
  0.3 to 1.9 times CPython's time on Russian, Chinese and French text
  ([measurements](https://github.com/den-run-ai/pystachy/blob/v0.6.0-alpha.3/bench/unicode_case/README.md));
  the `PYSTACHY_UNICODE_AUDIT` setting is removed.
  ([#1518](https://github.com/den-run-ai/pystachy/pull/1518))
- Float powers, rounding, `%` and `//`, comparisons of ints with floats, `bytes(list)` and
  masked 32-bit integer arithmetic run inline, and larger objects take a free slot without
  a call. ([#1436](https://github.com/den-run-ai/pystachy/pull/1436),
  [#1449](https://github.com/den-run-ai/pystachy/pull/1449),
  [#1437](https://github.com/den-run-ai/pystachy/pull/1437),
  [#1441](https://github.com/den-run-ai/pystachy/pull/1441),
  [#1447](https://github.com/den-run-ai/pystachy/pull/1447),
  [#1445](https://github.com/den-run-ai/pystachy/pull/1445))
- A range loop that indexes a list at a loop-invariant offset runs one checked test and then
  an unchecked loop that the Lean checker proves.
  ([#1450](https://github.com/den-run-ai/pystachy/pull/1450),
  [#1455](https://github.com/den-run-ai/pystachy/pull/1455))
- As opt-ins, `PYSTACHY_JIT_OPT=2` runs LLVM's -O2 pipeline in the JIT, and
  `PYSTACHY_PROFILE_GENERATE` and `PYSTACHY_PROFILE_USE` build an executable with a profile
  of its own runs. ([#1456](https://github.com/den-run-ai/pystachy/pull/1456),
  [#1444](https://github.com/den-run-ai/pystachy/pull/1444))

## Compiler internals

The typed IR defines each operation in one table, closes its operand spellings, prints and
parses as text, and has its shape proved in Lean. Frontend records leave the IR module, and
layout reads lower to machine operations before LLVM. None of this changes a compiled
program. ([#1541](https://github.com/den-run-ai/pystachy/pull/1541) to
[#1545](https://github.com/den-run-ai/pystachy/pull/1545),
[#1284](https://github.com/den-run-ai/pystachy/pull/1284),
[#1285](https://github.com/den-run-ai/pystachy/pull/1285))

## Correctness repairs

On Linux AArch64, the collector also scans the registers that `main` or an extension's entry
saves above its frame record, where LLVM could keep a pointer across an allocation that the
collector then freed. ([#1553](https://github.com/den-run-ai/pystachy/pull/1553))

## Known limits and platforms

Dynamic `Any` and promoting integers remain experimental opt-ins. Mapping patterns, async,
full native mypy and broad concurrency are outside this alpha. `x += y` on a value typed as
a class calls that class's `__add__` even where the object's subclass defines `__iadd__`
([#1538](https://github.com/den-run-ai/pystachy/issues/1538)). The
[compatibility reference](https://github.com/den-run-ai/pystachy/blob/v0.6.0-alpha.3/docs/language/compatibility.md)
lists the documented deviations.

| Native archive | Requirements |
|---|---|
| Linux x86-64 / AArch64 | Ubuntu 24.04 or compatible glibc 2.39+ Linux; LLVM 18 |
| macOS arm64 / x86-64 | macOS 15+, Xcode Command Line Tools; LLVM 20 |

Archives and Docker run without Python; the hosted compiler needs Python 3.11+ and reports
`commit unknown` when installed with pip. Full verification targets Linux x86-64 and ARM64
with CPython 3.13.16. Linux archives are not manylinux packages. Prereleases leave the
stable `latest` unchanged.
