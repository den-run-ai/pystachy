Pystachy v0.5.0-alpha.5 separates the compiler into explicit stages with a finalized typed-IR
boundary that tools can inspect before LLVM lowering, and fixes JIT discovery with symlinked
LLVM tools. Compiled programs are unchanged from alpha.4. It remains an experimental compiler
for a typed subset of Python.

## Compiler stages

The compiler now runs six attempt-owned stages: prepare, discover, analyze, optimize, finalize
and lower. Finalization exposes complete typed function bodies, representation tables and
validated C ABI plans before lowering consumes them, and module admission checks finish first.
A stage cannot repeat, run early, or resume after a failed or retried attempt.
[#1499](https://github.com/den-run-ai/pystachy/pull/1499),
[stage contract](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.5/docs/typed-ir.md#pipeline)

The hosted inspection prototype can stop after finalization, through the driver's own retry
path and without LLVM output, and binds each finalized snapshot to its report by SHA-256.
Preparation and discovery still combine typing, representation choices and specialization, so
the finalized program is not a portable semantic IR.
[Inspection](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.5/docs/compiler-inspection.md)

Generated IR, diagnostics and exit statuses equal alpha.4's for all 4,796 corpus programs, and
the Lean report's counts are unchanged. Self-compilation time is unchanged within measurement
noise, with 3.5 MiB lower peak memory.

## JIT launcher

The JIT launcher resolves a symlinked `lli` before it looks for `libLLVM`, and its cache no
longer reuses lookups that failed through the unresolved path.

## Verification, limits and platforms

A bounded Lean model checks stage order, terminal lowering, retries and the association of
inspection reports with attempts. It does not prove stage semantics or LLVM correctness. Dynamic
`Any` and promoting integers remain experimental opt-ins; async, full native mypy and broad
concurrency remain outside this release.
[Pipeline model](https://github.com/den-run-ai/pystachy/blob/v0.5.0-alpha.5/tools/lean_boundary/PIPELINE.md)

Native archives target Linux x86-64/AArch64 with glibc 2.39+ and LLVM 18, and macOS
arm64/x86-64 with macOS 15+, Xcode Command Line Tools and LLVM 20. Linux archives
are not manylinux packages. Archives and Docker run without Python; the hosted compiler
needs Python 3.11+. This prerelease keeps stable defaults at v0.4.0.
