Pystachy v0.4.0-rc.1 freezes the v0.4.0 feature set for final qualification. It combines
bounded structural matching, a native pytest runner, guarded list-loop optimization and
expanded compiler safety checks with targeted correctness and performance repairs.
Pystachy remains an experimental compiler for a typed subset of Python.

## Corrections since alpha.6

- Base-typed exception fields read subclass class defaults safely, including mutable
  defaults, instance overrides, missing attributes and sibling subclasses. This corrects
  the crash disclosed in alpha.6. Mutating an overridden base-class default remains outside
  the supported contract. [#1333](https://github.com/den-run-ai/pystachy/issues/1333)
- Empty-tuple list construction retains GC scanning until its element representation is
  known, preserving strings held by typed and generic lists. This isolated correction comes
  from [#1278](https://github.com/den-run-ai/pystachy/pull/1278); the broader proof stack is
  excluded.
- Inherited classmethods use the defining method's defaults in dynamic programs; enum
  formatting with an empty specification respects custom `__str__`; and `time.sleep()`
  accepts an `int | float` argument without generating invalid LLVM IR.
  [#1357](https://github.com/den-run-ai/pystachy/pull/1357),
  [#1349](https://github.com/den-run-ai/pystachy/pull/1349),
  [#1363](https://github.com/den-run-ai/pystachy/pull/1363)
- Guarded loop copies preserve inlining of eligible single-use callees, repairing the
  floating-point workload regression introduced by loop duplication. Callee size counts
  toward the existing code-growth limit.
  [#1336](https://github.com/den-run-ai/pystachy/pull/1336)

## Features carried from the alphas

- Bounded `match` supports literals, captures, alternatives, guards, fixed-length tuples and
  plain fields of statically known dataclasses. Mapping, starred and general sequence
  patterns remain unsupported.
  [Pattern contract](https://github.com/den-run-ai/pystachy/blob/v0.4.0-rc.1/docs/language/semantics.md#structural-patterns)
- The native pytest runner prepares a documented dialect for CPython, JIT and AOT, checking
  original collection and outcomes by default. Selected JSON-repair, CPython and mypy/mypyc
  tests are qualified through their original and adapted forms; complete upstream suites
  are outside its scope.
  [Runner](https://github.com/den-run-ai/pystachy/blob/v0.4.0-rc.1/docs/pytest-native.md),
  [upstream selections](https://github.com/den-run-ai/pystachy/blob/v0.4.0-rc.1/tests/upstream/pytest/README.md)
- Guarded list loops remove eligible repeated bounds checks while retaining a checked
  fallback. Private scalar dictionary lookups avoid unnecessary boxing.
  [Optimization contracts](https://github.com/den-run-ai/pystachy/blob/v0.4.0-rc.1/docs/typed-ir.md#optimizations)
- Typed-IR and optional Lean checks cover selected payload guards, bounds, entry liveness,
  integer storage and stack copies. These prove properties of normalized models, with
  explicit trusted boundaries; they do not prove whole-compiler or GC correctness.
  [Proof scope](https://github.com/den-run-ai/pystachy/blob/v0.4.0-rc.1/tools/lean_boundary/README.md)
- Compatibility improvements include CPython accelerator ordering in `heapq`, bounded
  `statistics.linear_regression`, exception classes as handler values, iterable defaults
  for `min`/`max`, path and environment APIs, and the updated JSON-repair port.
  [Library contracts](https://github.com/den-run-ai/pystachy/blob/v0.4.0-rc.1/lib/compatibility.md)
- Linux JIT uses a checked LLJIT launcher when supported. Cache, file-descriptor, exception
  identity and dictionary callback fixes accompany optional local-process, owned-buffer
  and native-I/O examples. Those examples add no general shared-heap threading or async
  Python support.
  [Installation](https://github.com/den-run-ai/pystachy/blob/v0.4.0-rc.1/docs/install.md),
  [examples](https://github.com/den-run-ai/pystachy/tree/v0.4.0-rc.1/examples)

## Known limits

Dynamic `Any` and promoting integers remain experimental opt-ins. Pre-existing issues
include promoting-integer tuple membership
([#1354](https://github.com/den-run-ai/pystachy/issues/1354)), class reads in circular-import
aliases ([#1382](https://github.com/den-run-ai/pystachy/issues/1382)) and closed standard
streams ([#1182](https://github.com/den-run-ai/pystachy/issues/1182)). See the
[compatibility reference](https://github.com/den-run-ai/pystachy/blob/v0.4.0-rc.1/docs/language/compatibility.md).

Async, broader language composition, new inference features, native compiler wheels,
libuv and numerical-worker drafts remain separate work. RC stabilization accepts fixes
within the frozen scope; [#1186](https://github.com/den-run-ai/pystachy/issues/1186) tracks
qualification and publication.

## Platforms

| Native archive | Requirements |
|---|---|
| Linux x86-64 / AArch64 | Ubuntu 24.04 or compatible glibc 2.39+ Linux; LLVM 18 |
| macOS arm64 / x86-64 | macOS 15+, Xcode Command Line Tools; LLVM 20 |

Archives and Docker run without Python; the hosted compiler needs Python 3.11+. Full
verification targets Linux x86-64 and ARM64 with CPython 3.13.16. macOS has narrower
installation and release coverage, with Intel macOS secondary. Linux archives are not
manylinux packages.
