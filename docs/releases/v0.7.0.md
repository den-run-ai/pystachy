Pystachy v0.7.0 expands the typed Python subset with nested classes, builtin-container subclasses, class-template inheritance and richer closed unions. It adds executable tracebacks, a checked text form of the compiler's typed IR, and an experimental WebAssembly target. This release includes the fixes made during both candidates and the final corrections below. Pystachy remains an experimental compiler; LLVM is the default native backend.

## Classes, typing and libraries

- Classes can be nested, local to a function that runs at most once, or derived from `list`, `dict` and supported `collections.abc` classes. `__getattr__` handles missing attributes. Class templates support subclasses of their specializations. ([classes](https://github.com/den-run-ai/pystachy/blob/v0.7.0/docs/language/typing.md#subclasses-of-class-templates), [alpha.1](https://github.com/den-run-ai/pystachy/releases/tag/v0.7.0-alpha.1))
- An `int` passed to a `float` annotation, or an enum member passed to an `int` or `str` annotation, keeps its Python type. Closed unions support tuples and more arithmetic and container operations. The library adds most of `enum`, `zlib.crc32()` and `zlib.adler32()`. ([typing](https://github.com/den-run-ai/pystachy/blob/v0.7.0/docs/language/typing.md), [stdlib](https://github.com/den-run-ai/pystachy/blob/v0.7.0/docs/stdlib.md))
- Equality tries the left method, the reflected method and then identity. Ordering enum members against unrelated operands raises CPython's `TypeError`, including the operator and operand order. ([#1706](https://github.com/den-run-ai/pystachy/pull/1706), [#1745](https://github.com/den-run-ai/pystachy/issues/1745))

## Final corrections

- `Counter.copy()` and `deque.copy()` preserve a subclass's type and constructor behavior; copies no longer silently become base-class objects. ([#1741](https://github.com/den-run-ai/pystachy/issues/1741))
- Comparisons and tuple searches pass builtin-container subclasses to user methods as their original objects. Shared list and dictionary storage retains subclass identity and aliases, including containers with several subclasses of the same builtin payload type. ([#1739](https://github.com/den-run-ai/pystachy/issues/1739), [#1763](https://github.com/den-run-ai/pystachy/issues/1763))
- Class methods called through template-subclass objects bind the actual class. Subclass writes to class attributes no longer overwrite the base class, and factories retain the subclass when constructor argument types differ. ([#1744](https://github.com/den-run-ai/pystachy/issues/1744))

## Errors, tools and verification

Linux executables print file, line and function tracebacks for uncaught exceptions. Chained exceptions, macOS and WebAssembly still print only the final line. `pystachy doctor` diagnoses installations; `pystachy check --semantic FILE.py` reports compilation errors without LLVM. ([command line](https://github.com/den-run-ai/pystachy/blob/v0.7.0/docs/getting-started.md), [alpha.3](https://github.com/den-run-ai/pystachy/releases/tag/v0.7.0-alpha.3))

Typed IR text includes source locations and a format version. The compiler and Lean checks cover more operand types, structured control flow and narrowed object reads. Field proofs explicitly identify trusted hidden container-header initialization; they do not prove that initialization from end to end. The compiler's own inference completes in one attempt. ([typed IR](https://github.com/den-run-ai/pystachy/blob/v0.7.0/docs/typed-ir.md), [proof limits](https://github.com/den-run-ai/pystachy/blob/v0.7.0/tools/lean_boundary/GUARDS.md#field-initialization))

## Known limits

WebAssembly runs from a source checkout, with Node or optional Wasmtime hosting. The direct backend supports typed callbacks and plain generators; unsupported operations can use LLVM/WASI. Automatic garbage collection remains disabled, and embedded callers supply their own native stack. ([Wasm setup and limits](https://github.com/den-run-ai/pystachy/blob/v0.7.0/wasm/README.md))

Dynamic `Any` and promoting integers remain experimental opt-ins. Existing gaps include mapping updates and numeric attributes through `Any`, NamedTuple comparisons through `Any`, builtin methods returned by `getattr()`, and typed `round()` on large values. Their follow-up work is deferred from this release. ([dynamic Any](https://github.com/den-run-ai/pystachy/blob/v0.7.0/docs/dynamic-any.md), [#1772](https://github.com/den-run-ai/pystachy/pull/1772), [#1773](https://github.com/den-run-ai/pystachy/pull/1773), [#774](https://github.com/den-run-ai/pystachy/issues/774), [#1777](https://github.com/den-run-ai/pystachy/issues/1777))

Other existing limits include package star imports without top-level export lists, unbound module globals that shadow builtins, imported exception-target names and secondary-base `isinstance()` checks. Verifier cost under GC stress and outstanding Lean rejections remain tracked. ([compatibility](https://github.com/den-run-ai/pystachy/blob/v0.7.0/docs/language/compatibility.md), [#1644](https://github.com/den-run-ai/pystachy/issues/1644), [#1643](https://github.com/den-run-ai/pystachy/issues/1643))

## Platforms

| Native archive | Requirements |
|---|---|
| Linux x86-64 / AArch64 | Ubuntu 24.04 or compatible glibc 2.39+ Linux; LLVM 18 |
| macOS arm64 / x86-64 | macOS 15+, Xcode Command Line Tools; LLVM 20 |

Archives and Docker run without Python. The hosted compiler needs Python 3.11+ and reports `commit unknown` when installed with pip. Full verification targets Linux x86-64 and ARM64 with CPython 3.13.16. Linux archives are not manylinux packages.
