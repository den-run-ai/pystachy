## Measurements

Compile scale (#1274), generated visitor programs ([gen_hier.py](scripts/gen_hier.py),
[gen_visit_bench.py](scripts/gen_visit_bench.py)), compared with mypyc 2.4.1 by
[cmp_mypyc.py](scripts/cmp_mypyc.py); all outputs identical to CPython's:

| Program | Before | After | mypyc |
|---|---|---|---|
| 100 classes × 100 sites, AOT `-O2` build | 251.5 s | 1.0 s | 19.5 s |
| 200 classes × 400 sites, AOT build | stopped after 9.5 min | 2.3 s | 69.7 s |
| 100 classes, 40M virtual calls, run (median of 3) | 0.43 s | 0.20 s | 0.86 s (CPython 4.69 s) |
| Same, JIT first run / cached rerun | 17.4 s / 0.73 s | 1.1 s / 0.27 s | |

Import sweep of unmodified mypy and mypyc (`tools/import_sweep.py`), all four PRs merged locally
([results](results/2026-11-11/import-sweep-integrated.json)): 27 of 242 modules compile (26
before); the `mypy_extensions` (72) and `librt` (72) first blockers are gone; the first blockers
are now `pprint` (100, `mypy/options.py`), `importlib` (55, mostly `mypyc/common.py`'s
`importlib.machinery`), `gc` (11), `inspect` (8), `contextlib.ExitStack` (6), `hashlib` (6).

First mypy code executed natively: upstream `mypy.cache`, unmodified, over the librt port
([cache_roundtrip.py](bench/cache_roundtrip.py)) writes the same 171 bytes and reads back the
same values as CPython running the mypyc-compiled mypy wheel with librt's C extension. At scale
([cache_bench.py](bench/cache_bench.py), median of 3) the native AOT run takes 0.13 s and the
mypyc wheel 0.04 s; on the codec alone ([librt_bench.py](bench/librt_bench.py)) 0.44 s against
the C extension's 0.25 s and 2.5 s for the port interpreted by CPython. `tools/librt_check.py`
(in #1276) found 560,000 identical read outcomes over random and corrupted data.

## What blocks `mypy.nodes` next

With throwing stand-ins for missing modules ([stand-ins/stdlib](stand-ins/stdlib), with the
librt and ast_serialize ones) and minimal patches on a scratch copy, recorded in
[nodes-blocker-chain.md](results/2026-11-11/nodes-blocker-chain.md):

1. an untyped `Final` class attribute holding a list or dict display (`nodes.py:3863`; 14 modules);
2. `MypyFile`'s annotated `defaultdict(set)` field made it a template: fixed by #1277;
3. `defaultdict(set)` stored where `dict[str, set[str]]` is declared (`errorcodes.py:14`):
   lib's `defaultdict` is a wrapper class, not a `dict` subtype;
4. `orjson: Any` before an optional import (`util.py:19`);
5. `dict[type[object], ...]` and `get_class_descriptors(cls: type[object])` with `inspect`
   (`util.py:374`): class objects as values (#805).

Elsewhere: `FlexibleAlias` (`bogus_type.py`, 80 modules with stand-ins), `NodeVisitor(Generic[T],
ExpressionVisitor[T], ...)` (generic bases, #962), `isinstance` with class tuples (needs a class-set
static type: today's reference unions are boxed), `platform.machine()`, `importlib.resources.files()`
for the bundled typeshed, `gc` as a compiler-known module.

## Follow-ups found along the way

- The runtime normalizes a codec name on every `s.encode("utf-8")` and `b.decode("utf-8")`
  (`runtime.py`'s `codec_of`); passing no name avoids it and made mypy's cache helpers 2× faster.
- A native growable byte buffer would remove the per-write chunk of `WriteBuffer`.
- Narrowing a `for` loop's target with `isinstance()` failed in a test (`'Node' object has no
  method 'add'`).

## Reproduce

As in [README.md](README.md#reproduce), with the four branches merged into one checkout, then
`python3 research/mypy-native/scripts/sweep.py ./pystachy OUT.json "$PKGS:research/mypy-native/stand-ins/stdlib:research/mypy-native/stand-ins" $PKGS/mypy $PKGS/mypyc`
for the stand-in sweep, and `python3 research/mypy-native/scripts/cmp_mypyc.py PROGRAM.py ./pystachy VENV/bin/python 3`
(a venv with `mypy==2.4.1` and `setuptools`) for a mypyc comparison.
