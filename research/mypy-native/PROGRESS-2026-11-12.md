# Native mypy: progress on 12 November 2026

Research branch material, not for `main`. Follows [PROGRESS-2026-11-11.md](PROGRESS-2026-11-11.md);
same inputs (mypy 2.4.1, librt 0.16.0, CPython 3.13.18, LLVM 18.1.3, a shared 4-vCPU VM).

## Does mypyc compile?

Not yet as a program. In the 11 November sweep, 13 of mypyc's 102 modules compile (the package
`__init__`s and leaves such as `mypyc.namegen`, `mypyc.crash`, `mypyc.codegen.cstring`), and
`mypyc.namegen`'s 5 upstream unit tests already run natively (`tests/upstream/pytest`, from
before this work). mypyc compiles a program by running mypy's parser, semantic analysis and
checker first, so running mypyc natively needs mypy's front end too.

The smallest mypyc closure with real content is its IR: `mypyc.ir.ops` eagerly imports 6
project modules, against 10 for `mypy.nodes` and 146 for `mypyc.irbuild.builder`. Its blocker
chain, with stand-ins and probe patches, is in
[results/2026-11-12/mypyc-ir-ops-chain.md](results/2026-11-12/mypyc-ir-ops-chain.md): seven
small typing and inference forms, runtime-length tuples of objects, class objects as values
(#805), and then generic visitors (`accept(self, visitor: RTypeVisitor[T]) -> T` over
`RTypeVisitor(Generic[T])` subclasses, #962), which also gate mypy's `NodeVisitor[T]`.

## Sweep with these changes

With the four PRs of 11 November and #1280 to #1282 merged locally, the stand-in sweep of
unmodified mypy and mypyc ([results/2026-11-12/import-sweep-with-stubs.json](results/2026-11-12/import-sweep-with-stubs.json),
the stand-ins of 11 November) still compiles 28 of 242 modules. The 14 modules whose first
blocker was `nodes.py:3863` moved on: 11 to `errorcodes.py:14` (`defaultdict(set)` stored where
`dict[str, set[str]]` is declared), 2 to `reachability.py:275` (a `TypeVar` with constraints) and
1 to `modules_state.py:20`. With stand-ins for `importlib.machinery`, `importlib.util` and
`sysconfig` too ([import-sweep-with-stubs-extended.json](results/2026-11-12/import-sweep-with-stubs-extended.json)),
mypyc's first blockers are `inspect` (28 modules, `mypyc/ir/func_ir.py`), `FlexibleAlias` (20),
`mypy/util.py:19` (19), `x or []` field inference in `mypyc/ir/deps.py:115` (11) and `gc` (8).

With #1283 and #1286 merged too ([import-sweep-with-stubs-extended-all.json](results/2026-11-12/import-sweep-with-stubs-extended-all.json)),
29 modules compile, and `mypyc.ir.deps` is the first of mypyc's IR modules among them (mypyc 14
of 102). mypyc's first blockers are now `mypy/util.py:374` (29 modules: `dict[type[object], ...]`,
class objects as values, #805), `inspect` (28), `FlexibleAlias` (20) and `gc` (8); mypy's are
`FlexibleAlias` (66), `errorcodes.py:14` (14), `contextlib.ExitStack` (6), `gc`, `ast` and
`util.py:374` (4 each). Stand-ins throw: these modules compile, they do not run.

Without stand-ins ([import-sweep-unmodified-all.json](results/2026-11-12/import-sweep-unmodified-all.json)),
the same build compiles 28 of 242 (27 on 11 November): `mypyc.ir.deps` needs no stand-in, so
mypyc is at 14 of 102 either way. The first blockers there are still library modules: `pprint`
(100), `importlib` (55), `gc` (11), `inspect` (8), `contextlib.ExitStack` (6), `hashlib` (6).

Two first blockers are larger than their counts suggest:

- `FlexibleAlias` (86 modules with stand-ins) is not an alias problem: mypy writes
  `def copy_modified(self, *, values: Bogus[list[Type]] = _dummy, ...)` with
  `_dummy: Final[Any] = object()` (`mypy/types.py:220`) and tests `values is not _dummy`. A
  parameter of a concrete type defaulting to a sentinel of another type needs a representation
  (a hidden "passed" flag, say) before `Bogus = FlexibleAlias[T, T]` helps.
- `mypy/util.py:374` (33 modules) is `fields_cache: Final[dict[type[object], list[str]]]` for
  `get_class_descriptors()` and `replace_object_state()`, which use `inspect.getmembers`,
  `__dict__` assignment and `setattr`/`getattr` by computed names. Class objects as keys
  (#805) are only the first of these.

Generic visitors (#962): #1298 covers visitors whose type arguments are concrete. Still open:
generic pass-through bases (`class BaseAnalysisVisitor(OpVisitor[GenAndKill[T]])`), multiple
generic bases (mypy's `NodeVisitor`, mypyc's `IRVisitor(ExpressionVisitor[Value],
StatementVisitor[None])`), a visitor held where its base is declared over two return-type
families, and subclasses of generic classes whose `__init__` binds type variables.

## Next

1. Generic visitors: a subclass of a specialized generic class (#962) and a method whose type
   variable a parameter's generic class binds, dispatched over the receiver's hierarchy.
2. Small forms in the chain: field inference of `and`/`or` over imported module constants
   (`may_be_immortal and HAVE_IMMORTAL`), which `guess` does not type yet.
3. Runtime-length tuples of objects (`tuple[RType, ...]`).
4. Library modules mypy's closure imports eagerly: `pprint`, `hashlib`, `platform`,
   `importlib.resources`, `importlib.machinery`, `sysconfig`.
