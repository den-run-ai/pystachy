Pystachy speed vs surface

Performance against the amount of unmodified Python that Pystachy runs, across 34 commits of main from the project's first day (8 October 2026) to 11 November 2026; dates are UTC. Measured 12 November 2026; scripts, raw data and this report are in research/speed-vs-surface-2026-11-12 on the branch claude/peaceful-faraday-2yr9q6.

Data sources

Sampled commits
One row per sampled commit on main from 7 October to 11 November 2026: CPython test methods passing, first-error causes, benchmarks that work, source size and compiler size.
AOT speed per benchmark and commit
Median AOT time of each benchmark at each sampled commit and of CPython 3.13.18 on the same source, measured pinned to one core on an idle 4-vCPU VM; speedup is CPython's time over the commit's.
Source size at every commit on main
Lines of compiler, shipped library and runtime source, and differential test counts, at each of the 660 first-parent commits on main.
Most common first errors, latest commit
The 15 most frequent first compiler errors among the CPython test methods v0.4.0-alpha.5 rejects, with the cause each was assigned.
Newly passing methods per sampled commit
Methods that pass at a sampled commit but not at the previous one, by the cause of their first error at the previous one.
Unmodified upstream pyperformance files
Whether each of the 52 pyperformance 1.14.0 benchmark files compiles with only pyperf's runner replaced, the first sampled commit that compiled it, and its first error at the latest commit.
Largest speed changes and their causes
The biggest AOT time changes between consecutive sampled commits, with the merge that caused each where a bisection over the first-parent merges in between found it, or the merges the interval contains.
Latest commit with CPython's standard library added
Where the methods blocked by a missing library piece stop when CPython 3.13.16's pure-Python standard library is on the import path, at v0.4.0-alpha.5.
Performance index per commit (calculated)
Geometric mean of the per-benchmark AOT speedups over CPython 3.13 at each sampled commit: over the 16-port pyperformance core set where all 16 were measured, and over the six day-one microbenchmarks.
Findings since v0.1.0-alpha.2 (calculated)
Methods passing at v0.1.0-alpha.2 and gained since, compiler lines added since, the share of typing and dynamic-model first errors in language tests at the latest commit, and methods unlocked from each since the release.
