## Explicit proof limits

The completed 94f4 census records **542 rejected union reads and 409 associated unproved payload-bit obligations**, in 21 functions across nine added complex fixtures. Both counters share a joint verdict; each function is listed once under union. Review explains the first conservative-null-domain failure and does not prove later obligations. The final census reconciles these exact residuals explicitly in the semantic disposition. [Complex review](complex-residuals.md).

`complex_values.py` adds **three instances of the existing copy memo-get GC model gap**, increasing the full known GC gap from 375 to 378; these differ from the three gaps in the focused enum check. The new Decimal fixture retains unsupported field inference with an unknown count. These limits remain visible in the final disposition. Bounded proof models, source review and runtime tests do not establish whole-compiler or collector correctness.
